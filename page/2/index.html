第 7 讲 数字图像基础（图像基本概念 / Pillow / 手写数字数据集）

本讲对应课件：7.1 数字图像基本概念 → 7.2 Pillow 图像处理库 → 7.3 手写数字数据集。
这是深度学习实战前的”图像数据”准备篇：先搞清数字图像在计算机里到底怎么存（像素、位深度、色彩模式、格式），再学会用 Pillow 把图像读进来、看属性、转色彩模式、拆通道、转成 NumPy 数组、缩放旋转裁剪，最后用经典的 MNIST 手写数字数据集 把整条链路跑通。

应用层

概述

应用层是计算机网络体系结构的最顶层，是设计和建立计算机网络的最终目的，也是计算机网络中发展最快的部分：
    a、早期基于文本的应用（电子邮件、远程登录、文件传输、新闻组）
    b、20世纪90年代将因特网带入干家万户的万维网WWW
    c、当今流行的即时通信、P2P文件共享及各种音视频应用
    d、计算设备的小型化和“无处不在”，宽带住宅接入和无线接入的日益普及和迅速发展，为未来更多的新型应用提供了广阔的舞台。

网络层

概述

1、主要任务：实现网络互联，进而实现数据包在各个网络之间的传输。
2、实现网络层需要解决的问题：
    a、网络层需向运输层提供什么样的服务：可靠传输还是不可靠传输；
    b、网络层寻址问题：如何标识和寻找网络上的主机(接口)；
    c、路由选择问题：源站选择怎样的路径到达目的站。
3、因特网(Internet)是目前全世界用户数量最多的互联网，它使用TCP/IP协议栈。
4、由于TCP/IP协议栈的网络层使用网际协议IP，它是整个协议栈的核心协议，因此在TCP/IP协议栈中网络层常称为网际层
