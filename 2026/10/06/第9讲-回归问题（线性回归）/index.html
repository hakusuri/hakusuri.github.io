9.1 机器学习基础

9.1.1 从数据中学习

课件用一句农谚开场——“日晕三更雨，月晕午时风”——引出从经验（数据）中总结规律这件事。

机器学习：从数据中学习的算法。以房屋销售记录为例：

  1. 建立模型：假设房价与面积之间存在某种关系；
  2. 学习模型：用已有的销售记录（数据）确定模型中的参数；
  3. 预测房价：给定新的面积，用模型算出价格。

其中”学习算法“的定义是：从数据中产生模型的算法。

9.1.2 监督学习与核心术语

监督学习（Supervised Learning）：通过对有标记数据的学习，寻找属性和标记之间的映射关系。

术语 含义
数据集（data set）/ 样本集（sample set） 全部样本的集合
示例（instance）/ 样本（sample） 一条记录
属性（attribute）/ 特征（feature） 描述样本的输入量（如房屋面积）
标记 / 标签（label） 要预测的输出量（如房价）
模型 / 假设 / 估计函数 / 学习器（learner） 学到的映射关系
真相 / 真实（ground truth） 样本本来的真实输出

按输出类型分为两大类：

任务 输出
回归（regression） 预测连续值（本讲主题：预测房价）
分类（classification） 预测离散值（如判断是否为垃圾邮件）

9.1.3 无监督学习与半监督学习

  • 无监督学习（Unsupervised Learning）：在样本数据没有标记的情况下，挖掘出内部蕴含的关系。典型任务是聚类——把相似度高的样本聚合在一起。
  • 半监督学习（Semi-Supervised Learning）：将有监督学习和无监督学习相结合，综合使用大量没有标记的数据和少量有标记的数据共同进行学习。

9.1.4 机器学习的发展和应用

课件给出”人工智能 → 机器学习 → 深度学习“的层次关系，并用多张图展示了机器学习在各行业的应用。

9.2 一元线性回归

9.2.1 模型

一元线性回归（Simple Linear Regression）：

符号 名称 含义
x 变量 输入特征（如房屋面积）
w 权重（weights） 直线的斜率
b 偏置值（bias） 直线的截距
y 输出 预测值（如房价）

9.2.2 最佳拟合直线：为什么要用平方

最佳拟合直线应该使得所有点的残差累计值最小。课件比较了三种度量：

度量 表达式 问题
残差和最小 Σ(yᵢ - yᵢ') 正负残差会相互抵消
残差绝对值和最小 Σ&#124;yᵢ - yᵢ'&#124; 绝对值不便求导
残差平方和最小 Σ(yᵢ - yᵢ')² ✅ 可导、无抵消

因此采用平方损失函数（Square Loss）。

9.2.3 损失函数与最小二乘法

  • 损失函数 / 代价函数（cost function）：估量模型的预测值与真实值的不一致程度。

本讲易错点清单

  1. 解析解公式的分子分母别写反：w = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)²，分子是”x 的偏差 × y 的偏差”，分母是”x 的偏差平方和”。
  2. b = ȳ - w·x̄：算出 w 之后代回去算 b，别忘减号。
  3. 多元回归必须补一列 1：x₀ = 1 对应偏置 b = w₀；漏了这一列，W[0] 就没有意义，回归平面也画不对。
  4. np.stack((x0, x1, x2), axis=1)：要按列堆叠成 n×3；写成 axis=0 会变成 3×n，矩阵乘法直接错。
  5. (XᵀX)⁻¹ 存在的条件：XᵀX 必须是满秩矩阵（样本数要足够、属性之间不能完全线性相关），否则求逆会报错或得到不可靠结果。
  6. 形状对齐：X 是 n×(m+1)、W 是 (m+1)×1、Y 是 n×1；Y 别忘了 reshape(-1, 1)。
  7. 求出的 W 是二维的：需要 reshape(-1) 压成一维，才能用 W[0]/W[1]/W[2] 取参数。
  8. TensorFlow 用 .numpy()、PyTorch 用 .item() 取标量值；PyTorch 的张量在打印时带 tensor(...) 外壳。
  9. 三维绘图要建 Axes3D 对象：fig = plt.figure(); ax3d = Axes3D(fig)，之后用 ax3d.scatter / plot_surface / plot_wireframe，不要再用 plt.xxx。
  10. 画曲面前必须先 np.meshgrid()：X、Y、Z 三者形状要一致（如都是 (100, 100)）。
  11. 中文显示：plt.rcParams['font.sans-serif'] = ['SimHei']，否则标题和图例会变方框。
  12. os.environ['KMP_DUPLICATE_LIB_OK'] = 'TRUE'：PyTorch 与 NumPy/MKL 同用时可能报 OpenMP 重复加载错误，课件用这行规避。
