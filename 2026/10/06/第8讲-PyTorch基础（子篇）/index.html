8.7.1 PyTorch 简介

8.7.1.1 PyTorch 是什么

1. 由来

  • PyTorch 是 2017 年 1 月由 **FAIR（Facebook AI Research，Facebook 人工智能研究院）**发布的一款深度学习框架。
  • 从名称可以看出，PyTorch = Python + Torch：
    • Torch 是纽约大学在 2012 年发布的一款机器学习框架，采用 Lua 语言作为接口；
    • 但 Lua 语言较为小众，导致 Torch 知名度不高；
    • PyTorch 是在 Torch 基础上，用 Python 语言进行封装和重构打造而成的。
  • PyTorch 是基于 Python 的科学计算包，其优点在于能让研究人员、爱好者快速研发出小规模项目模型，并具有较强的可编程性和灵活性。

2. 两个常用定位

PyTorch 既可以看作加入了 GPU 支持的 NumPy，同时也可以看成一个拥有自动求导功能的强大的深度神经网络。

除 Facebook 外，它已经被 Twitter、Salesforce 等机构采用。

3. 主要优点（课件归纳的四点）

优点 说明
易于学习和使用 使用 Python 语言编写，非常适合 Python 开发者使用，并且提供了简洁的 API 和文档；语法与 Python 非常相似，同时具有直观的命令式编程风格
丰富的生态系统 包括各种数据处理库、预训练模型、可视化工具等；与 NumPy、SciPy 等流行 Python 库无缝集成，使数据处理和科学计算更加便捷
强大的 GPU 加速支持 提供内置的 GPU 支持，可充分利用高性能图形处理器（GPU）加速模型的训练和推断；提供简单易用的 API，使用户无缝地将模型迁移到 GPU 上，从而加快训练速度和提高性能
大型社区支持 拥有庞大而活跃的社区，可以获取支持、交流经验，且有大量开源项目和教程可供学习和参考；社区不断推出新的功能、工具和模型

8.7.1.3 PyTorch 框架特性

课件把 PyTorch 的框架特性归纳为：灵活的动态计算图、自动求导、GPU 加速、灵活的模型构建和训练、丰富的预训练模型和模型库等。下面取三条最核心的展开。

1. 灵活的动态计算图

  • PyTorch 使用动态计算图，允许用户按需构建、修改和调试模型，而不需要事先定义整个计算图，减少了开发过程中的复杂性。
  • 在 PyTorch 中，计算图是由节点（节点代表张量操作）和边（边代表张量）组成的有向无环图。
  • 用户可以通过执行张量操作来构建计算图，每个张量操作都会生成新的节点并连接到计算图中；这意味着用户可以使用 Python 的**控制流语句（如 if 语句、for 循环等）**来定义复杂的模型结构，而不仅仅局限于静态图中预定义的操作。
  • 尽管使用了动态计算图，但为了提高计算效率，PyTorch 会在运行时对计算图进行优化，并将其转化为静态图进行执行——这种混合的动态-静态图执行方式既保留了动态计算图的灵活性，又提供了静态图执行的高效性能。

2. 张量计算

PyTorch 提供了强大的张量计算功能，张量（Tensor）是 PyTorch 的核心数据结构。张量可以进行高效的数学运算、线性代数操作、数组操作等，支持 GPU 加速计算，使得模型训练和推理更加高效。

3. 自动求导

  • PyTorch 能够自动计算张量的梯度（自动求导）：通过将代码中的张量定义为可求导变量，PyTorch 会自动跟踪计算过程并生成计算图，然后通过反向传播算法计算梯度。
  • 自动求导机制是深度学习中非常重要的功能，它使得我们能够方便地计算损失函数对模型参数的梯度，从而进行模型的优化。
  • 在 PyTorch 中，自动求导机制是通过 torch.autograd 模块实现的。

API 速查（本节涉及）

8.7.1.4 自动求导机制的基本步骤（先睹为快）

课件给出使用自动求导机制的 4 个基本步骤：

  1. 创建张量，并设置 requires_grad 标志为 True，以告知 PyTorch 需要对该张量进行梯度计算；
  2. 定义计算图和损失函数，使用创建的张量进行计算，得到最终的损失；
  3. 调用 backward() 方法，自动计算损失函数对张量 x 的梯度；
  4. 访问张量的 grad 属性，即可获取计算得到的梯度值。

注：课件抽取出的损失函数只剩 loss + =(y + -10)，** 2 没有出现在文本流里。这是本套课件代码字体的一个系统性现象——**（双星号）常整对丢失（单星号 * 正常，如 y=3*x+2 就完整保留；8.7.5 的 print(A ** 3) 同样被抽成 print(A + 3)）。按输出 tensor([-30.]) 反推，其定义应为 loss = (y - 10) ** 2。校验：$x=1 \Rightarrow y=5 \Rightarrow loss=25$，$\partial loss/\partial x = 2(y-10)\cdot 3 = 2\times(-5)\times 3 = -30$，与课件输出一致。

注意事项：

  • 自动求导机制默认只能对标量进行求导，即只能计算一个标量损失函数对一个标量张量的导数；
  • 如果需要对向量或矩阵进行求导，需要对损失函数进行逐元素求和或平均，以得到一个标量，然后再进行求导；
  • 自动求导机制还支持动态计算图，即可以根据需要随时修改计算图的形状和结构，这使得 PyTorch 非常适合用于构建动态、灵活的模型。

8.7.1.5 易错点

  1. 忘记 requires_grad=True：张量创建时没有声明需要求导，调用 backward() 时会报 “element 0 of tensors does not require grad” 之类的错误。
  2. 对非标量直接求导：loss 若不是标量（0 维张量），需要先 .sum() 或 .mean() 降到标量，再调用 backward()。
  3. 梯度累加：.grad 是累加的，同一个张量多次 backward 会不断叠加（详见 8.7.6）。
  4. 动态图 ≠ 没有图：PyTorch 依然是“先建图、再反向”的机制，只是建图发生在运行时；这也是它支持 Python 控制流的原因。
  5. 不要把“动态图”理解成“性能一定差”：课件明确说明运行时会把图优化后按静态图执行（混合动态-静态图）。

8.7.2.7 易错点

  1. torch.tensor() 与 torch.Tensor() 不是一回事：torch.tensor() 是工厂函数，会按输入推断 dtype；torch.Tensor() 是类构造，默认得到 float32 张量且传 list 的行为不同。
  2. 共享内存的两处陷阱：torch.from_numpy()、out= 参数都与原对象共享内存。想断开联系要显式 .clone() / .copy_()。
  3. arange 不含 end，linspace 含 end——这是最容易混淆的一对；linspace 的第三个参数是元素个数，不是步长。
  4. logspace 的第 4 个位置参数是 base，写成位置参数时极易看错成 steps。
  5. dtype 推断：torch.tensor([1, 2, 3]) 是 int64，torch.full((3, 3), 9) 是 float（因为 fill_value 是浮点语义），而 torch.arange(9) 是 int64；需要精确控制时显式传 dtype。
  6. torch.empty 的内容是不确定的：不要对它的数值做任何假设，用之前必须自己赋值。
  7. 随机数函数的 shape 参数写法：randn/rand 用 *sizes（可写 torch.randn(2, 3)），randint/bernoulli 等要传 size 元组，混用会报参数错误。

（1）torch.expand() 和 torch.repeat()：维度扩展

8.7.3.6 易错点

  1. reshape 的元素数必须守恒：形变维度的乘积要等于张量元素个数，否则报 “shape … is invalid for input of size …”。
  2. squeeze(dim) 只对长度为 1 的维度生效：b.squeeze(1) 中维度 1 的长度是 32，所以形状不变——不会报错，但也没效果，容易误判为 bug。
  3. unsqueeze 的索引范围：对 $n$ 维张量，合法范围是 $[-n-1, n]$；a.unsqueeze(5) 就超界了（a 是 4 维，范围 [-5, 4]）。
  4. expand 与 repeat 的语义差别：expand 要求被扩展的那一维原本必须是 1（或写成 -1 保持原样），且返回的是视图；repeat 是真正复制数据，参数含义是“每个维度重复几次”，所以 b.repeat(4, 32, 1, 1) 会把 32 维变成 $32 \times 32 = 1024$。
  5. t() 只适用于 ≤ 2 维：更高维要用 transpose 或 permute。
  6. shape 是属性、size() 是方法：写成 t.shape() 会报 “‘torch.Size’ object is not callable”。
  7. flatten 之后维度信息丢失：反复 flatten / reshape 时要自己记住原始形状，否则无法还原。

8.7.4 部分采样

在 PyTorch 中，我们可以通过索引、切片、gather 等函数从张量中取出需要的部分数据。本小节按“基本索引 → 切片索引 → 数据提取函数 → 合并与分割”的顺序展开。

8.7.4.1 基本索引

变量 a 是一个 (3 x 3) 的 2D 张量，即张量 a 包含两个维度：

  • 第一个维度，在 2D 张量中称为行维度；

  • 第二个维度，在 2D 张量中称为列维度。

  • a[0] 表示在张量 a 的行维度上取索引号为 0 的元素（第一行）；

  • a[0][1] 表示在张量 a 的行维度上取索引号为 0 的元素（第一行），以及在列维度上取索引号为 1 的元素（第二列），获取行维度和列维度上的元素集合的交集（位于第一行第二列上的元素）即为最终的索引结果。

简单来说，[i][j]...[k] 中的每一个 `` 都表示张量的一个维度，从左边开始维度依次增加，而 [] 中的元素值代表对应维度的索引号；此时的索引号可以为负数，相当于从后向前索引。

当张量的维度数较高的时候，使用 [i][j]...[k] 的方式书写非常不方便，可以采用 [i, j, ..., k] 的方式，两种方式是等价的。

8.7.4.4 合并与分割

（1）torch.cat 和 torch.stack

可以用 torch.cat 方法和 torch.stack 方法将多个张量合并，也可以用 torch.split 方法把一个张量分割成多个张量。

两者的区别：torch.cat 是连接，不会增加维度；torch.stack 是堆叠，会增加一个维度。

（2）torch.split 和 torch.chunk

torch.split() 和 torch.chunk() 可以看作是 torch.cat() 的逆运算。

  • split()：作用是将张量拆分为多个块，每个块都是原始张量的视图。函数定义：torch.split(tensor, split_size_or_sections, dim=0)
  • chunk()：作用是将 tensor 按 dim（行或列）分割成 chunks 个 tensor 块，返回的是一个元组。函数定义：torch.chunk(input, chunks, dim=0) -> List of Tensors

split 的两种用法：第二个参数给整数时表示“每块的大小”（最后一块可能不足）；给列表时表示“每一块的长度”（列表元素之和必须等于该维度的长度）。

chunk 与 split 的差别：chunk 的参数是“分成几块”，尽量均分（除不尽时前面的块更大），返回元组；split 的参数是“每块多大”。

8.7.4.5 易错点

  1. 切片是前闭后开：a[3:9] 取的是下标 3~8，不含 9。
  2. [i][j] 与 [i, j] 等价，但不能混着乱写：a[0, 1] 是标量 tensor(1)，a[0][1] 也是 tensor(1)，但 a[0:1][1] 与 a[0:1, 1] 的含义完全不同（前者先切行再对结果取第 2 行）。
  3. b[:, 2] 降维：结果为 1D（torch.Size([3])），而 b[:, 2:3] 保留维度（torch.Size([3, 1])）。在拼接/广播前要特别注意。
  4. gather / index_select 的 index 必须是整型张量（int64），传 float 会报错。
  5. gather 的 index 维度数必须与 input 相同，形状决定了输出的形状——这是 gather 与 index_select 最大的区别。
  6. cat 与 stack 混淆：cat 沿已有维度拼接（不增加维度），stack 新建一个维度堆叠（维度 +1）。合并 $n$ 个 (3,3) 张量，cat(dim=0) 得到 (9,3)，stack(dim=0) 得到 (3,3,3)。
  7. dim 与 axis 参数名可混用（如 torch.stack(..., axis=0)），但为了让代码更规范，建议统一写 dim。
  8. split 用列表时元素之和必须正好等于该维长度，否则报错。

8.7.5.2 广播机制

（1）广播机制定义

如果一个 PyTorch 操作支持广播，则其 Tensor 参数可以自动扩展为相等大小（不需要复制数据）。通常情况下，小一点的数组会被“广播”到稍大一些，这样才能保持大小一致。

（2）广播机制规则

如果遵守以下规则，则两个 tensor 是可广播的：

  1. 每个 tensor 至少有一个维度；
  2. 遍历 tensor 所有维度时，从末尾开始遍历，两个 tensor 存在下列情况之一：
    • tensor 维度相等；
    • tensor 维度不等且其中一个维度为 1；
    • tensor 维度不等且其中一个维度不存在。

如果两个 tensor 是可广播的，则计算过程遵循下列规则：

  • 如果两个 tensor 的维度不同，则在维度较小的 tensor 的前面增加维度，使它们维度相等；
  • 对于每个维度，计算结果的维度值取两个 tensor 中较大的那个值；
  • 两个 tensor 扩展维度的过程是将数值进行复制。

8.7.5.5 易错点

  1. * 是逐元素乘，@ 才是矩阵乘：a * b 是点乘（Hadamard 积），矩阵乘法要用 torch.mm / torch.matmul / @。
  2. torch.Tensor([...]) 默认 float32，torch.tensor([...]) 按输入推断整型：课件在乘除法示例里用大写 Tensor，所以输出是小数的 tensor([ 2., 4., ...])。
  3. 除法默认不做舍入：torch.div 的 rounding_mode=None 得到浮点结果；要整除需要显式传 rounding_mode='trunc' 或 'floor'。
  4. torch.round 的“四舍六入五成双”：0.5 → 0、1.5 → 2、2.5 → 2，是按“最接近的偶数”舍入，不是简单的四舍五入。
  5. torch.fmod 结果的符号跟被除数一致：torch.fmod(-3, 2) = -1，而 Python 的 % 会得到 1。
  6. torch.log(0) = -inf：对数函数对 0 输入会输出负无穷，做损失函数前要加 eps 保护。
  7. max(dim=) 返回的是命名元组，需要 values, indices = A.max(dim=1) 或 A.max(dim=1).values 取用，不能直接当张量运算。
  8. 广播不是“自动对齐”：必须从末尾维度开始逐维比较，且较小的那个 tensor 只在前面补维；(5,2,4,1) 与 (3,1,1) 在倒数第三维上是 2 vs 3，无法广播（课件例 3）。
  9. 广播的扩展是“逻辑上复制”：expand / 广播都不真正复制数据，写原地操作（如 x += y）时若广播结果被引用要小心。
  10. mm 不支持批量：3 维及以上必须用 bmm 或 matmul。

8.7.6.4 梯度下降法

梯度下降法是一种求函数极值的数值解的算法，是一个一阶最优化算法；和解析解不同，数值解一般是通过迭代来实现的。

对于机器学习算法，只要能够把损失函数描述成凸函数，那么就一定可以采用梯度下降法，以最快速度更新权值向量，找到使损失函数达到最小值点的位置；能够在每次迭代时自动调节步长，确定更新方向。

一元凸函数迭代算法：

$$x^{(k+1)} = x^{(k)} - \eta \frac{df(x^{(k)})}{dx}$$

二元凸函数迭代算法：

$$x^{(k+1)} = x^{(k)} - \eta \frac{\partial f(x^{(k)}, y^{(k)})}{\partial x}$$

$$y^{(k+1)} = y^{(k)} - \eta \frac{\partial f(x^{(k)}, y^{(k)})}{\partial y}$$

注：课件公式为图片化排版，抽取出来的公式文本不完整（如“dxxdf xkkx )()1(”）。上式为按上下文还原的标准形式，其中 $\eta$ 为学习率（课件中以“步长”表述）。

8.7.6.5 损失函数

以一元线性回归问题为例，其平方损失函数为：

$$L(s_i, y_i) = \sum_i (s_i - y_i)^2, \qquad s_i = w x_i + b$$

均方损失函数（课件第二种写法）：

$$L = \frac{1}{2}\sum_i \left( y_i - (w x_i + b) \right)^2$$

注：课件两种损失函数的抽取文本完全糊化，系数（1/2、1/n）无法直接从抽取结果辨认。本笔记按 8.7.6.6 中的求导结果反推：课件给出的 $\partial Loss/\partial w = \sum_i x_i (w x_i + b - y_i)$ 恰好对应 $L = \frac{1}{2}\sum_i (w x_i + b - y_i)^2$，故此处保留 1/2 系数并标注出处。

8.7.6.8 易错点

  1. 梯度会累加：.grad 是累加的，训练循环里每轮更新前必须 optimizer.zero_grad() 或 w.grad.zero_()。
  2. backward 后计算图默认被销毁：想对同一张量重复调用（或先 backward 再 grad），要设 retain_graph=True。
  3. torch.autograd.grad 不写 .grad：它只返回梯度值列表，所以打印出来带括号，如 (tensor(12.),)。
  4. requires_grad=True 的变量才在梯度图里：如果不设置，.grad 会是 None（或直接报错）。
  5. 参数更新要放在 torch.no_grad() 下：否则更新过程本身会被记入计算图，造成显存泄漏或梯度语义混乱。
  6. x.grad 与 x.data 的区别：.data 绕过了 autograd 追踪，直接改 .data 有风险，优先用 with torch.no_grad():。
  7. 标量才能直接 backward：非标量输出必须给 grad_tensors / grad_outputs，或者先 sum() / mean() 降成标量。
  8. only_inputs 与 allow_unused：only_inputs=False 会把梯度也累加到各叶子节点的 .grad 上；allow_unused 默认 False，传了未被用到的 input 会直接报错。
  9. 学习率太大容易发散：梯度下降法自身对步长敏感，一元线性回归的 $w, b$ 量纲不同，收敛速度可能差异很大。
