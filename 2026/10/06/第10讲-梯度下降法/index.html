10.1 梯度下降原理

10.1.1 解析解与数值解

求解线性回归模型本质上是函数求极值问题。课件先区分两类解法：

解法 定义 特点
解析解（Analytical solution） 根据严格的推导和计算得到的解 是方程的精确解，能够在任意精度下满足方程
数值解 通过某种近似计算得到的解 能够在给定的精度下满足方程

第 9 讲用的最小二乘法/正规方程就是解析解；本讲的梯度下降属于数值解（迭代法）。

10.1.2 用迭代法逼近极小值

课件用最简单的一元凸函数 y = x² + 2 演示”试探 + 迭代“的过程：每次从当前点出发，看往哪个方向走、走多远，能让函数值更小。

迭代的核心公式：

  • η 称为学习率（步长）；
  • 它同时干了两件事：自动确定下一次更新的方向（梯度的反方向）、自动调节步长；
  • 只要 loss 能描述成凸函数，就一定能用梯度下降法以最快速度更新权值向量，找到使损失函数达到最小值点的位置。

10.1.3 步长（学习率）的影响（课件三张表）

以 y = x² + 2、初值 x₀ = 3 为例：

步长 现象 课件结论
0.2 3 → 2.8 → 2.6 → ... → 0.2 → 0，逐次逼近 正常收敛
0.5 3 → 2.5 → 1.5 → 0.5 → 0，两次就到位 收敛很快
0.7 3 → 2.3 → 0.9 → 0.2 → -0.5 → 0.2 → -0.5 ... 震荡（overshoot the minimum），在极小值两侧来回跳

课件给出的结论：

  • 步长太小：迭代次数多、收敛慢；
  • 步长太大：引起震荡，可能无法收敛。

10.1.4 二元凸函数与梯度的几何意义

对二元函数 f(x, y)：

  • 模：等于方向导数的最大值；
  • 方向：是取得最大方向导数的方向。

因此沿梯度的反方向走，函数值下降最快——这正是”梯度下降”这个名字的由来。

10.2.5 归一化（数据预处理）

在多元回归中，各属性的取值范围可能相差几个数量级（面积上百、房间数个位数），因此需要归一化：

  • 定义：将数据的值限制在一定的范围之内；
  • 目的：使所有属性处于同一个范围、同一个数量级下，更快收敛到最优解，并提高学习器的精度；
  • 三种方式：
方式 做法 公式
线性归一化 对原始数据做线性变换、等比例缩放，所有数据被映射到 [0, 1] 之间 x' = (x - min) / (max - min)
标准差归一化 将数据集归一化为均值为 0、方差为 1 的标准正态分布 x' = (x - μ) / σ
非线性映射归一化 对原始数据做非线性变换 指数、对数、正切等

10.5 模型评估

10.5.1 误差与泛化

  • 误差（error）：学习器的预测输出和样本的真实标记之间的差异。
  • 训练误差（training error）：训练集上的误差。
  • 泛化误差（generalization error）：在新样本上的误差。

10.5.2 过拟合与欠拟合

现象 含义 表现
过拟合（overfitting） 学习过度 在训练集上表现很好，在新样本上泛化误差很大
欠拟合（underfitting） 学习不足 没有学习到样本中的通用特征

10.5.3 训练集与测试集

  • 机器学习的目标：泛化误差小；
  • 训练集（training set）：训练模型用；
  • 测试集（testing set）：测试学习器在新样本上的预测或判断能力；
  • 测试误差（testing error）：用来近似泛化误差。

实践要点：只能用训练集来训练参数，测试集在训练过程中不能参与参数更新——否则测试误差就不再是泛化误差的近似。本讲 10.6 的实现里，每一步都会同时记录 loss_train 和 loss_test，但只有 loss_train 被用于求梯度。

本讲易错点清单

  1. 学习率先小后大：太小收敛慢，太大震荡甚至发散。课件在商品房数据上先用 0.00001、归一化后用 0.2、波士顿数据用 0.04——学习率与数据尺度强相关。
  2. 参数必须用 tf.Variable：普通 Tensor 没有 assign、trainable；用错会直接报 AttributeError。
  3. 更新参数用 assign_sub（w.assign_sub(lr*dL_dw)），不是 w = w - lr*dL_dw（后者会把 Variable 变成普通 Tensor，丢掉可训练性）。
  4. GradientTape 默认只能求一次梯度；需求多次要 persistent=True，并在最后 del tape 释放资源。
  5. watch_accessed_variables=False 时记得 tape.watch(x)，否则梯度返回 None。
  6. 损失里的 0.5：0.5 * mean(square(...)) 是为了求导时约掉平方的系数 2；一旦写成 0.5*...，梯度就恰好是 (pred - y)·x 的均值——如果用均方差损失就必须除以 n，否则学习率要同步缩小 n 倍。
  7. 多元回归必须补一列 1：X = concat([x0, x_train], axis=1)，参数个数 = 属性数 + 1。
  8. 归一化只用训练集的 min/max：测试集必须用同一组统计量，否则尺度不一致。
  9. 测试集不参与训练：loss_test 只记录、不用于 tape.gradient，否则测试误差就不再是泛化误差的近似。
  10. 过拟合的信号：训练损失持续下降而测试损失触底回升——此时应停止训练或加正则化。
  11. 广播的方向：x.min(axis=0) 是”每列的最小值”（沿行方向聚合），别和 axis=1 搞混。
  12. tf.concat vs np.stack：拼接既有张量用 tf.concat（不增加维度），从零构造增广矩阵用 np.stack(..., axis=1)。
