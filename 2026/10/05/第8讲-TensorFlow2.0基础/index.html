8.1 TensorFlow 2.0 特性

8.1.1 TensorFlow 是什么

课件的定位是 An end-to-end open source machine learning platform（端到端的开源机器学习平台）：

  • end-to-end（端到端）：从数据到模型再到部署，一整套流程都在框架内完成；
  • open source（开放源代码）：开放设计和实现框架；
  • machine learning（机器学习生态）：不只是库，而是一个生态系统。

课件还列了 TensorFlow 的几篇代表性论文/系统：TensorFlow: Large-Scale Machine Learning on Heterogeneous Distributed Systems、Wide & Deep Learning for Recommender Systems、The YouTube Video Recommendation System。

8.1.2 发展历程

时间 版本 关键内容
2011 DistBelief TensorFlow 的前身
2015.11 TensorFlow 0.5.0 首次开源发布
2017.02 TensorFlow 1.0 高层 API，将 Keras 库整合其中；动态图机制 Eager Execution；面向移动终端的 TensorFlow Lite；面向网页前端的 TensorFlow.js；自动生成计算图的 AutoGraph
2019 TensorFlow 2.0 见下（易用性、API 清理）

8.1.3 静态图 vs 动态图（本讲最核心的一组对比）

TensorFlow 1.x 的延迟执行机制（deferred execution）/ 静态图机制：

  • 分为构建阶段和执行阶段：上面代码只是描述了计算图，并没有实质的计算发生，真正的计算发生在会话（Session）中运行计算图时；
  • 优点：代码运行效率高，便于优化；
  • 缺点：程序不够简洁。

TensorFlow 2.0 的动态图机制（Eager Execution）：

  • 无需首先创建静态图，可以立刻执行计算，并返回结果；
  • 能够快速地建立和调试模型；
  • 缺点：执行效率不高。

课件的工程结论（要记住这个权衡）：

兼顾易用性和执行效率——在程序调试阶段使用动态图，快速建立模型、调试程序；在部署阶段采用静态图机制，从而提高模型的性能和部署能力。

8.1.4 清理重复、冗余的 API

TensorFlow 1.x 中构建神经网络的方式很多：tf.slim、tf.layers、tf.contrib.layers、tf.keras——混乱，不利于程序共享，维护成本高。

TensorFlow 2.0：清理、整合了重复的 API，并将 tf.keras 作为构建和训练模型的标准高级 API。

8.1.5 TensorFlow 框架特性

  • 多种环境支持：可运行于移动设备、个人计算机、服务器、集群等；覆盖云端、本地、浏览器、移动设备、嵌入式设备；
  • 支持分布式模式：TensorFlow 会自动检测 GPU 和 CPU，并充分利用它们并行、分布地执行；
  • 简洁高效：构建、训练、迭代模型用 Eager Execution + Keras；部署阶段转化为静态图以提高执行效率；
  • 社区支持：众多企业使用 TensorFlow 提供解决方案。

8.2.2 为什么需要张量：Tensor / list / ndarray 对比

类型 特点
张量（Tensor） 可以高速运行于 GPU 和 TPU 之上，实现神经网络和深度学习中的复杂算法
Python 列表（list） 元素可以使用不同的数据类型、可以嵌套；在内存中不是连续存放的，是一个动态的指针数组；读写效率低、占用内存空间大；不适合做数值计算
NumPy 数组（ndarray） 元素数据类型相同；每个元素占用空间相同，存储在连续的内存区域中；存储空间小、读写速度快；但不能够主动检测利用 GPU 进行运算

一句话：Tensor = 能做 GPU 加速的 ndarray。

8.2.3 tf.constant()：创建张量

张量由 Tensor 类实现，每个张量都是一个 Tensor 对象：

参数 说明
value 数字 / Python 列表 / NumPy 数组
dtype 元素的数据类型
shape 张量的形状

参数为 Python 列表：

.numpy() 方法：TensorFlow 2.0 中所有的张量都可以通过 .numpy() 得到它对应的数组。

参数为数字：TensorFlow 创建浮点数张量时，默认是 32 位浮点数；单独一个数字是 0 维张量 / 数 / 标量。

8.2.4 张量元素的数据类型

类型 描述
tf.int8 8 位有符号整数
tf.int16 16 位有符号整数
tf.int32 32 位有符号整数
tf.int64 64 位有符号整数
tf.uint8 8 位无符号整数
tf.float32 32 位浮点数
tf.float64 64 位浮点数
tf.string 字符串（非 Unicode 编码的字节数组）
tf.bool 布尔型
tf.complex64 复数，实部和虚部分别为 32 位浮点型

参数为 NumPy 数组时的坑：NumPy 创建浮点数数组时默认是 64 位浮点数，所以用 NumPy 数组创建张量时，TensorFlow 会接受数组元素的数据类型，用 64 位浮点数保存数据；需要手动指明 dtype=tf.float32。

tf.cast(x, dtype)：改变张量中元素的数据类型——转换时自动将低精度的数据类型向高精度转换。

布尔型：布尔型转换为整型 → 0: False、1: True；整型转换为布尔型 → 非 0 数都视为 True。

字符串：b'...' 中的 b 表示这是一个字节串。Python3 中字符串默认是 Unicode 编码，要转成字节串就在原来的字符串前加 b。

8.2.5 其他创建方式

函数 功能
tf.constant(value, dtype, shape) 创建张量
tf.convert_to_tensor() 由数组 / 列表 / 数字 / 布尔型 / 字符串创建张量
tf.zeros(shape, dtype=tf.float32) 创建全 0 张量
tf.ones(shape, dtype=tf.float32) 创建全 1 张量
tf.fill(shape, value) 创建元素值全部相同的张量
tf.random.normal() 创建元素取值符合正态分布的张量
tf.random.truncated_normal() 创建元素取值符合截断正态分布的张量
tf.random.uniform(shape, minval, maxval, dtype) 创建元素取值符合均匀分布的张量
tf.range(起始数, 结束数, 步长) 创建元素取值为整数序列的张量

判断函数：tf.is_tensor()、isinstance()（判断是不是张量）。

  • 默认为 32 位浮点数；zeros 函数用法和 ones 相同；
  • 形状既可以用 shape=(2, 1)，也可以用方括号 [2, 3] 表示。

tf.fill()：tf.fill(形状, 填充的数)——没有 dtype 参数，根据 value 参数自动判断数据类型。

tf.constant() 建同值张量：tf.constant(填充的数, shape=形状)——为避免混淆，建议加上参数名称。

创建随机数张量：

参数为：形状、均值、标准差、数据类型（默认 32 位浮点数）。

截断正态分布 tf.random.truncated_normal()：截断的标准是 2 倍的标准差。例如均值为 0、标准差为 1 时，用 tf.truncated_normal() 不可能出现区间 [-2, 2] 以外的点；而用 tf.random_normal() 则可能出现。

设置随机种子 tf.random.set_seed()：设置随机种子，可以产生同样的随机数张量。

均匀分布 tf.random.uniform()：参数是最小值、最大值，区间前闭后开，不包括最大值。

随机打乱 tf.random.shuffle()：参数可以是张量、Python 列表或 NumPy 数组，随机打乱第一维。

创建序列 tf.range()：前闭后开，不包括结束数。

8.2.6 Tensor 对象的属性

属性名形式为 .变量名：

  • ndim：返回张量的维度；
  • shape：返回张量的形状；
  • dtype：元素数据类型；
  • 还可用函数获得元素总数（tf.size()）。

8.2.7 张量和 NumPy 数组的关系（重要）

  • 在 TensorFlow 中，所有的运算都是在张量之间进行的；NumPy 数组仅仅是作为输入和输出来使用；
  • 张量可以运行于 CPU，也可以运行于 GPU 和 TPU；而 NumPy 数组只能够在 CPU 中运行。

8.3 维度变换

8.3.1 张量的存储和视图

课件用”班级—组—序号”的比喻讲这件事：

  • 逻辑组织：视图——例如”2 班.3 组.6 号”；
  • 物理组织：存储——多维张量在物理上以一维的方式连续存储，通过定义维度和形状，在逻辑上把它理解为多维张量。

核心结论：当对多维张量进行维度变换时，只是改变了逻辑上索引的方式，没有改变内存中的存储方式。

8.3.2 改变张量的形状：tf.reshape()

  • tf.reshape() 没有封装到 Tensor 对象中，前缀是 tf，而不是张量对象的方法；
  • shape 参数中的 -1 表示自动推导出长度。

8.3.3 多维张量的轴（axis）

  • 轴就是张量的维度：0 维张量 shape ()；1 维 (4,) 轴为 0；2 维 (3, 4) 轴为 0、1；3 维 (2, 3, 4) 轴为 0、1、2；
  • 轴也可以是负数，表示从后向前索引：-3, -2, -1；
  • 张量中轴的概念和用法，和 NumPy 数组完全一样。

8.3.4 增加和删除维度

增加维度 tf.expand_dims()：增加的这个维度上长度为 1。

删除维度 tf.squeeze()：

  • 只能删除长度为 1 的维度；
  • axis 省略时删除所有长度为 1 的维度。

例：tf.squeeze(tf.ones([1, 2, 1, 3, 1]), axis=[2, 4]) → shape 变为 (1, 2, 3)。

重要区别：增加维度和删除维度，只是改变了张量的视图，不会改变张量的存储。

8.3.5 交换维度：tf.transpose()

  • 对二维张量交换维度，就是矩阵的转置；
  • 可以调整张量中各个轴的顺序： 改变轴的顺序，从而改变张量的形状。例：三维张量按 perm=[2, 0, 1] 交换，即”最后一维不变、前两维交换”。

与 reshape 的关键差别：交换维度不仅改变了张量的视图，同时也改变了张量的存储顺序。

8.3.6 拼接和分割

拼接 tf.concat()：

  • 将多个张量在某个维度上合并；
  • 拼接并不会产生新的维度；
  • 例：两个 (2, 3) 张量在 axis=0 拼接 → (4, 3)（2+2=4）；在 axis=1 拼接 → (2, 6)（3+3=6）。

分割 tf.split()：

  • 将一个张量拆分成多个张量，分割后维度不变；
  • 分割方案：
    • 是一个数值时 → 等长分割，数值是切成的份数；
    • 是一个列表时 → 不等长切割，列表中是切分后每份的长度。
  • 例：[1, 2, 1] 表示分割成 3 个张量，长度分别是 1、2、1。

图像的分割（tf.split）改变了张量的视图，张量的存储顺序并没有改变。

8.3.7 堆叠和分解

堆叠 tf.stack()：

  • 在合并张量时，创建一个新的维度；
  • 和 NumPy 中堆叠函数的功能完全一样；
  • 例：3 个 shape (3,) 的张量，在 axis=0 堆叠 → (3, 3)；在 axis=1 堆叠 → (3, 3)（形状含义不同）。

分解 tf.unstack()：

  • 是张量堆叠的逆运算；
  • 把张量分解为多个张量；
  • 分解后得到的每个张量，和原来的张量相比，维数都少了一维。

8.5.3 广播机制（broadcasting）

  • 一维张量 + 二维张量：要求两个张量最后一个维度的长度必须相等；
  • 一维张量 + 三维张量：同样要求最后一个维度的长度相等；
  • 数字 + N 维张量：当张量和一个数字进行运算时，会把这个数值广播到张量的各个元素。

8.5.4 张量与 NumPy 数组之间的相互转换

  • NumPy 数组 → 张量：tf.constant()、tf.convert_to_tensor()；
  • 张量 → NumPy 数组：Tensor.numpy()。

共同参与运算时的规则：

  • 执行 TensorFlow 操作 → TensorFlow 将自动把 NumPy 数组转换为张量；
  • 执行 NumPy 操作 → NumPy 将自动把张量转换为 NumPy 数组。

使用运算符操作：只要操作数中有一个 Tensor 对象，就把所有的操作数都转化为张量，然后再进行运算（运算符重载为张量加法）。

8.5.5 张量乘法（重点区分）

类型 函数 / 运算符 说明
元素乘法 tf.multiply()、* 运算符 对应位置元素相乘
向量乘法（矩阵乘法） tf.matmul()、@ 运算符 按线性代数规则相乘

多维向量乘法的规则（重要）：

  • 最后两维做向量乘法；
  • 高维采用广播机制。
例子 过程
三维 × 二维 (3,5) × (5,4) → (3,4)，再与另一维广播成 (2,3,4)
三维 × 三维 (2,3) × (3,2) → (2,2)，广播后 (2,2,2)
四维 × 四维 同样”最后两维相乘 + 高维广播”，得到 (2,2,2,2)

8.5.6 数据统计

对张量在某个维度上、或者全局求统计值：

函数 描述
tf.reduce_sum(input_tensor, axis) 求和
tf.reduce_mean(input_tensor, axis) 求平均值
tf.reduce_max(input_tensor, axis) 求最大值
tf.reduce_min(input_tensor, axis) 求最小值

均值函数的类型坑（课件重点强调）：

结论：张量元素的数据类型是 int32，求得的均值也是 int32（小数被截掉）。想要精确均值，要么元素用浮点数，要么先用 tf.cast() 转成浮点数。

求最大值、最小值：tf.reduce_max()、tf.reduce_min()。

求最值的索引：tf.argmax()、tf.argmin()——没有指定 axis 参数时，默认 axis=0。

本讲易错点清单

  1. 默认数据类型：TensorFlow 用 tf.constant(1.0) 建浮点张量默认是 32 位；而用 NumPy 数组创建时会继承 NumPy 的 64 位浮点，想统一要显式 dtype=tf.float32。
  2. int 求均值会截断：tf.reduce_mean 对 int32 张量求均值结果仍是 int32，务必先 tf.cast(a, tf.float32)。
  3. tf.reshape 是函数不是方法：写成 tf.reshape(b, [4, -1])，不是 b.reshape(...)；-1 表示自动推导。
  4. reshape / expand_dims / squeeze 只改视图，不改变存储；而 tf.transpose 会改变存储顺序。
  5. tf.squeeze 只能删长度为 1 的维度；不写 axis 时删除所有长度为 1 的维度。
  6. tf.concat 不增加维度，tf.stack 会增加一个维度；两者别混。
  7. 切片前闭后开：[0:5] 取的是 0~4；负步长时起始索引要大于结束索引。
  8. 切片只能做连续/有规律采样，不规则采样要用 tf.gather（单轴）或 tf.gather_nd（多维多坐标）。
  9. 元素乘法 vs 矩阵乘法：* / tf.multiply 是逐元素，@ / tf.matmul 才是矩阵乘法（最后两维相乘 + 高维广播）。
  10. argmax/argmin 默认 axis=0，不指定轴时是按列找最值。
  11. 对数只有自然对数 tf.math.log，换底请用换底公式；sqrt/exp/log 要求浮点类型。
  12. 除法会改变 dtype：a / b（int32 相除）结果为 float64。
