13.1 小批量梯度下降法

13.1.1 为什么要用梯度下降（课程回顾）

  • 多层神经网络解决非线性分类问题；
  • 其损失函数不是凸函数，很难计算解析解；
  • 因此通常采用梯度下降法，得到数值解（对照第 9 讲的解析解：只有线性回归那种凸问题才有封闭解）。

课件把求解函数极值的方法分为三类：批量梯度下降、随机梯度下降、小批量梯度下降。

13.1.2 批量梯度下降（BGD，Batch Gradient Descent）

每次迭代都使用所有样本来计算偏导数，由所有样本确定梯度方向：

优点 缺点
每一步都是准确地向着极值点趋近，迭代次数少；收敛于全局极小值或局部极小值点；可以利用向量运算进行并行计算 计算量大、训练时间长，不适合大规模数据集

课件的算量例子：样本集 20 万个样本、迭代 10 次 → 计算量 20 万 × 10 = 200 万。

13.1.3 随机梯度下降（SGD，Stochastic Gradient Descent）

  • 每次迭代只选择一个样本训练模型，使网络的输出尽可能逼近这个样本的标签值；
  • 一轮（epoch）：使用所有样本训练一遍；反复训练多轮，直到网络对所有样本的误差足够小。
缺点 说明
参数更新非常频繁 无法快速收敛
不易于实现并行计算 每次只有一个样本

⚠️ 术语提醒（课件原话）：“随机梯度下降”通常是指小批量梯度下降算法——实际工程里说的 SGD，绝大多数指的是下一节的 MBGD，而不是严格的”每次一个样本”。

13.1.4 小批量梯度下降（MBGD / Mini-Batch SGD）

把数据分为多个小批量，每次迭代使用一个小批量来训练模型：

关键性质：

  1. 每个小批量中的所有样本共同决定本次迭代的梯度方向；
  2. 一轮 = 使用所有小批量训练一遍；需要训练多轮，使网络对所有样本的误差足够小；
  3. 每次迭代的训练样本数固定，与整个训练集的样本数量无关——这一点很重要：批量大小是超参数，不会被数据集规模改变；
  4. 可以实现并行运算，适合训练大规模数据集。

课件的两个算例：

样本集 分批数 每批样本数
2000 个样本 10 批 200
200000 个样本 1000 批 200

注意第二行：数据集扩大 100 倍，批量大小仍然是 200——这正是第 3 条性质的体现。

13.1.5 抽样（Sampling）与梯度偏差

  • 抽样：从数据集中随机抽取出来一部分样本，它们的特征可以在一定程度上代表完整数据集的特征；
  • 独立同分布（i.i.d.）：小批量样本能够代表整个样本集的特征；
  • 随机抽取：小批量样本的特征和整体样本的特征存在差别。

小批量梯度下降的”偏差”是好事还是坏事：

  • 小批量样本计算出的梯度和使用全体样本计算出的标准梯度之间存在偏差；
  • 但总体上向最优化的方向前进；
  • 而且这种随机性提高了模型的泛化能力（相当于给训练加了噪声，不容易过拟合训练集）。

课件用等高线损失函数 z=f(x,y) 的图演示了小批量迭代的路径（不是笔直指向极小值，而是曲折地趋近）。

13.2 梯度下降法的优化

13.2.1 课程回顾：梯度、驻点与局部极小

  • 函数在某一点的梯度：是一个向量；
  • 梯度方向：函数值变化最快的方向；
  • 沿着损失函数的梯度方向更新权值：
  • 驻点：导数为 0 的点（凸函数中是极小值点）；
  • 梯度为零时，停止迭代；
  • 非凸函数：存在局部极小值点与鞍点——所以”多层神经网络使用梯度下降法，无法保证一定可以收敛于全局最小值点“。

13.2.2 影响小批量梯度下降法的主要因素

课件列出三个因素：小批量样本的选择、批量大小（mini-batch size）、学习率。

（1）小批量样本的选择：打乱样本顺序

  • 数据集的连续的样本之间有高度的相关性（比如鸢尾花数据是按类别排好序的）；
  • 因此在每轮训练之前，打乱样本顺序（对应 model.fit(..., shuffle=True)）。

（2）批量大小（mini-batch size）

批量大小 效果
越大 梯度方向越准确，迭代次数越少
越小 随机性越大，迭代次数越多
= 1 即随机梯度下降法
= 整个数据集 即批量梯度下降法

工程建议（课件）：为充分利用处理器资源、进行并行计算，批量大小取 2 的幂数：32、64、128、256。

（3）学习率

  • 学习率设置过小，收敛速度慢；设置过大，震荡、无法收敛（同第 10 讲的结论）；
  • 分两类做法：固定学习率 与 动态调整学习率（在训练过程中动态调整）。

学习率衰减（Learning Rate Decay）/ 学习率退火（Learning Rate Annealing）：

  • 开始训练时设置较大学习率，加快收敛速度；
  • 迭代过程中，学习率随着迭代次数逐渐减小，避免震荡。

对凸函数，学习率单调减小即可稳定收敛；对非凸函数，光靠衰减还不够，于是有了下面的自适应方法与动量法。

13.2.3 自适应学习率算法

算法 核心思想
AdaGrad 有一个全局学习率，同时各个参数自适应地调整学习率；学习率随着迭代次数的增加而单调减小
RMSprop 改进了 AdaGrad 调整学习率的方法
AdaDelta 同属改进 AdaGrad 的一类；各参数的学习率不是单调递减的

三者的共同点：自适应地调整每个参数的学习率；区别在于 AdaGrad 单调递减、RMSprop/AdaDelta 不单调（避免学习率过早衰减到 0）。

13.2.4 动量梯度下降法（Momentum）

动量的物理直觉：动量 = 质量 × 速度。

核心思想：在更新参数时，可以在一定程度上保留之前的更新方向。

效果：

  • 梯度方向不变时：步长更大，收敛加快；
  • 梯度方向改变时：步长变小，更新变慢（动量起”惯性阻尼”作用，抑制震荡）。

13.2.5 牛顿加速梯度算法（NAG，Nesterov Accelerated Gradient）

在 Momentum 基础上再进一步：

  • 根据当前更新方向，估算下一步的梯度方向；
  • 在新位置求梯度，修正梯度方向。

Momentum vs NAG：Momentum 是”先走一步再看当前梯度”；NAG 是”先按惯性预估到新位置，在新位置算梯度再修正“——相当于提前刹车，收敛更稳。

13.2.6 优化器家族全景（课件总结图）

Adam = 自适应学习率 + 动量，所以它是实践中最常用的默认优化器（13.4 的编译里用的就是 Adam / SGD）。

13.3 Keras 与 tf.keras

13.3.1 Keras 是什么

  • 由 Python 编写的开源人工神经网络库；
  • 特点：
    • 面向对象，完全模块化；
    • 支持神经网络和深度学习的主流算法；
    • 支持多操作系统下的多 GPU 并行计算；
    • 作为深度学习库的前端计算引擎（后端可以是 TensorFlow、CNTK、Theano）。

13.3.2 Keras 与 tf.keras 的两种安装路线

路线 说明
Keras with TensorFlow Backend 安装 Keras 时，TensorFlow 作为依赖项被自动安装
tf.keras 安装 tensorflow 时，tf.keras 作为子模块被自动安装；它是 TensorFlow 的高阶 API

13.3.3 TensorFlow 2.0 + tf.keras

  • 解决了 1.x 版本中存在的问题，并有大量的优化和扩展；
  • 一句话概括两者的关系：TensorFlow 具备 Keras 的简单性，Keras 具备 TensorFlow 的强大性。

这也是第 8 讲”TensorFlow 2.0 把 tf.keras 作为构建和训练模型的标准高级 API”的延续。

13.4 Sequential 模型

13.4.1 tf.keras 与模型（model）

  • tf.keras：TensorFlow 的高阶 API，可以快速搭建和训练神经网络模型；
  • 它的主要数据结构是模型（model）。

Sequential 模型：

  • 是神经网络框架；
  • 只有一组输入和一组输出；
  • 各个层按照先后顺序堆叠（这就是 “Sequential” 的含义）。

13.4.2 建立 Sequential 模型

两种写法（课件同时给出）——先建模型，再逐层添加：

  • tf.keras.layers.Dense：全连接层（此外还有卷积层、池化层）；
  • 参数含义：输入该网络层的数据、激活函数、input_shape 输入数据的形状（只有第一层需要指定）；
  • 也可以把层写成一个列表一次传入（课件第一种写法 model = tf.keras.Sequential() 后逐层 add）。

本讲易错点清单

  1. “SGD”通常指小批量梯度下降：课件明确说明；严格的”每次一个样本”反而是特例。
  2. 一轮（epoch）≠ 一次迭代：一轮 = 所有小批量（或所有样本）各训练一遍；迭代次数 = 轮数 × 每轮批次数。
  3. 批量大小与数据集大小无关：数据集从 2000 扩到 200000，批量仍是 200；批量大小是超参数。
  4. 批量大小取 2 的幂（32/64/128/256）：为了充分利用并行计算资源。
  5. 每轮训练前必须打乱样本顺序：连续样本之间高度相关，不打乱会让梯度方向有系统性偏差。
  6. 小批量的梯度有偏但方向正确，而且能提高泛化能力——不要因为”不够精确”而拒绝小批量。
  7. 非凸函数（多层网络）不保证收敛到全局最小：可能停在局部极小或鞍点；这才需要学习率衰减、动量与自适应优化器。
  8. 学习率衰减/退火：先大后小；AdaGrad 单调递减，RMSprop/AdaDelta 非单调。
  9. Momentum vs NAG：Momentum 用当前梯度 + 历史速度；NAG 先在”预判位置”求梯度再修正。
  10. Adam = 自适应学习率 + 动量；Adam(lr=..., beta_1=0.9, beta_2=0.999)。
  11. Sequential 只有一组输入/输出，层按顺序堆叠；要分支/多输入输出得用函数式 API（本讲未涉及）。
  12. 只有第一层需要 input_shape；后续层的输入形状由上一层自动推断。
  13. 参数量公式 = 输入维数 × 输出维数 + 输出维数（偏置）：如 784×128+128 = 100480。
  14. from_logits：输出层已 softmax 就写 from_logits=False，输出层没 softmax 才写 True。
  15. Sparse 前缀 = 标签是顺序码数值；没有 Sparse = 标签是独热编码。标签/预测值的”形式”和损失、指标必须配套（否则 loss 会是天文数字或直接报错）。
  16. Dense 只吃一维特征：图像要先 reshape 或加 Flatten 层。
  17. evaluate 返回列表：[loss, metric]；verbose=2 每个 epoch 一行。
  18. load_weights 前必须重建同结构模型，否则 NameError 或形状不匹配；load_model 才能一步到位。
  19. save_weights(..., overwrite=False) 遇到同名文件会交互式询问，脚本里要留意。
  20. predict 返回概率分布：要得到类别必须 np.argmax。
