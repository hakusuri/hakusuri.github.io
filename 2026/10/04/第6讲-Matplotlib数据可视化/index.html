第 6 讲 Matplotlib 数据可视化

导读：本讲解决”用 Python 把数据画出来”的问题，含 5 个小节：6.1 Matplotlib 绘图基础（画布、子图、中文字体、标题、自动布局）、6.2 散点图（scatter()、marker、图例）、6.3 折线图和柱状图（plot()、bar()）、6.4 波士顿房价数据集可视化、6.5 鸢尾花数据集可视化（下载数据集、Pandas 读 csv、按类别着色画散点图），文末为 tight_layout() 参数补充说明。

6.1 Matplotlib 绘图基础

6.1.1 为什么可视化 · 安装与导入

数据可视化贯穿三个阶段：数据分析阶段（理解数据、洞察数据之间的关系）、算法调试阶段（发现问题、优化算法）、项目总结阶段（展示项目成果）。Matplotlib 是第三方库，可快速方便地生成高质量图表（直方图、柱形图、折线图、散点图、气泡图、三维图等）。

  • 安装：Anaconda 装好后 Matplotlib 已就绪；也可 pip 安装。
  • 导入：import matplotlib.pyplot as plt

6.1.2 Figure 对象：创建画布

Figure 对象就是画布，用 plt.figure() 创建。流程为创建画布 → 绘制图形 → 显示绘图。

参数 说明
num 图形编号或名称，取值为数字 / 字符串
figsize 绘图对象的宽和高，单位为英寸
dpi 分辨率，缺省值为 80
facecolor / edgecolor 背景颜色 / 边框颜色
frameon 是否显示边框

常用颜色缩略字符：blue b、black k、green g、white w、red r、cyan c、yellow y、magenta m。

6.1.3 划分子图：subplot() 与轴域（Axes）

轴域（Axes） 是真正画图的区域，一个 Figure 上可放多个轴域。语法：subplot(行数, 列数, 子图序号)。

  • 每个 subplot() 只创建一个子图；要创建 4 个子图就需要 4 条语句。
  • 3 个参数都小于 10 时，可省略逗号，用一个 3 位数表示（subplot(221) 等价于 subplot(2,2,1)）。
  • 序号排布：1×2 → 1 2；1×3 → 1 2 3；2×2 → 1 2 / 3 4；2×3 → 1 2 3 / 4 5 6。

例：将画布划分为 2×2 子图区域并绘制 3 个子图。

6.1.4 设置中文字体

Matplotlib 默认字体不含中文，需通过运行配置参数 rcParams（指定图表各种默认属性的全局变量）设置：

常用中文字体英文描述：宋体 SimSun、楷体 KaiTi、黑体 SimHei、仿宋 FangSong、微软雅黑 Microsoft YaHei、隶书 LiSu、微软正黑体 Microsoft JhengHei、幼圆 YouYuan。也可直接写 plt.rcParams["font.family"] = "SimHei"。

6.1.5 标题：suptitle() 与 title()

suptitle() 添加全局标题；title() 给当前子图添加子标题。

suptitle() 主要参数：x（默认 0.5）、y（默认 0.98）、color（黑）、backgroundcolor、fontsize、fontweight（light/normal/medium/semibold/bold/heavy/black，默认 normal）、fontstyle（normal/italic/oblique）、horizontalalignment（默认 center）、verticalalignment（默认 top）。

title() 主要参数：loc（left/right/center）、rotation（旋转角度）、color、fontsize、fontweight、fontstyle、fontdict（设置参数字典）。

6.1.6 tight_layout() 自动调整子图

tight_layout() 会检查坐标轴标签、刻度标签和子图标题，自动调整子图，使之填充整个绘图区域并消除子图之间的重叠。rect=[left, bottom, right, top]（0~1 归一化坐标）指定子图区域，默认 (0, 0, 1, 1)。

6.1.7 综合示例

6.1 易错点

  • 忘记 plt.show()，图形不会显示；一个 subplot() 只画一个子图。
  • 中文字体不设置会显示方块；设字体后负号可能异常，需同时设 axes.unicode_minus=False。
  • suptitle() 是画布级标题、title() 是子图标题，不要混用；子图重叠用 tight_layout()。

6.2 散点图

6.2.1 概念与 scatter() 函数

散点图（Scatter） 是数据点在直角坐标系中的分布图，用于发现数据的分布规律、变化趋势与分组。

语法：scatter(x, y, scale=..., color=..., marker=..., label=...)

参数 说明 默认值
x / y 数据点的 x / y 坐标 不可省略
scale 数据点的大小 —
color 数据点的颜色 —
marker 数据点的样式 'o'（圆点）
label 图例文字 —

marker 常用取值：- 实线、-- 虚线、: 点线、-. 点虚线、s 正方形、p 五角形、o 圆形、| 垂直线、_ 水平线、v/^/</> 朝下/上/左/右的三角形、D 钻石形、d 小版钻石形、* 星型、+ 加号、x x 号、1/H 六角形。

6.2.2 文本与坐标轴设置

text() 函数：text(x, y, s, fontsize=..., color=...)，其中 x、y、s（显示文本）均不可省略，color 默认黑色。

坐标轴设置：xlabel() 设置 x 轴标签；ylabel() 设置 y 轴标签；xlim(xmin, xmax) / ylim(ymin, ymax) 设置坐标范围；tick_params(labelsize) 设置刻度文字字号。

6.2.3 完整示例：标准正态分布散点图

6.2.4 多组数据与图例 legend()

用绘图函数的 label 指定图例内容，再用 plt.legend() 显示；loc 指定位置：0 best、1 upper right、2 upper left、3 lower left、4 lower right、5 right、6 center left、7 center right、8 lower center、9 upper center、10 center。

例：同时绘制标准正态分布与均匀分布两组散点。

6.2 易错点

  • scatter() 的 x、y 与 text() 的 x、y、s 不可省略；text() 换行用字符串 \n。
  • 只写 legend() 而绘图时没有 label=，图例为空。

6.3 折线图和柱状图

6.3.1 折线图与 plot() 函数

折线图（Line Chart）：在散点图基础上，将相邻的点用线段相连接，描述变量变化的趋势。

plot() 函数：

参数 说明 默认值
x 数据点的 x 坐标 0,1,2,3…（可省略）
y 数据点的 y 坐标 不可省略
color / marker 颜色 / 数据点样式 marker 默认 'o'
label 图例文字 —
linewidth / markersize 折线宽度 / 数据点大小 —

例：绘制温度和湿度数据的折线图。

6.3.2 柱形图与 bar() 函数

柱形图（Bar Chart）：由一系列高度不等的柱形条纹表示数据分布的情况。bar() 函数关键参数：left（条纹 left 坐标，用 range(len(y)) 自动生成序列）、height（条纹高度）、width（条纹宽度，示例取 0.8，即每隔 1cm 开始画一个条纹）、facecolor、edgecolor、label。

例：绘制柱形图。

预期输出：绿色柱向上、红色柱向下（负值），两组”统计量”共用同一坐标系。

6.3.3 参考资源：Matplotlib 官网 Gallery

官网 http://matplotlib.org；函数索引 https://matplotlib.org/genindex.html；Gallery 页面 https://matplotlib.org/gallery.html：缩略图列表，点进详细页面可看到清晰大图与源码。

6.3 易错点

  • plot() 的 x 可省略（默认 0,1,2…），y 不可省略。
  • bar() 不写 left 时柱形会全部堆在 0 处；画负值柱形需设 axes.unicode_minus=False。
  • 多条折线/柱形分别设 label 后统一调用一次 plt.legend()。

6.4 波士顿房价数据集可视化

6.4.1 Keras 与内置数据集

Keras 是高层的神经网络和深度学习库，可快速搭建神经网络模型、易于调试和扩展，是 TensorFlow 的官方 API，内置常用公共数据集，可通过 keras.datasets 模块加载访问：boston_housing（波士顿房价）、CIFAR10（10 类图片集）、CIFAR100（100 类图片集）、MNIST（手写数字图片集）、Fashion-MNIST（10 种时尚类别图片集）、IMDB（电影点评）、reuters（路透社新闻）。

6.4.2 波士顿房价数据集

来自卡内基梅隆大学 StatLib 库，1978 年；涵盖麻省波士顿 506 个不同郊区的房屋数据；默认 404 条训练数据、102 条测试数据；每条数据 13 个属性 + 1 个房价平均值。

6.5 鸢尾花数据集可视化

6.5.1 下载鸢尾花数据集

Iris 数据集：又名 Anderson’s Iris Data Set，1936 年由 Ronald Fisher 发表（The use of multiple measurements in taxonomic problems）；采样条件严格（加拿大的加斯帕半岛、同一天的同一个时间段、相同牧场、同一个人、相同的测量仪器）。共 3 种类别：山鸢尾 Setosa、变色鸢尾 Versicolour、维吉尼亚鸢尾 Virginica，每类 50 个样本；每个样本含 4 个属性（花萼长度 Sepal Length、花萼宽度 Sepal Width、花瓣长度 Petal Length、花瓣宽度 Petal Width）和 1 个标签（品种）。

get_file() 函数：tf.keras.utils.get_file(fname, origin, cache_dir=...)

参数 说明
fname 下载后的文件名
origin 文件的 URL 地址
cache_dir 下载后文件的存储位置

返回值：下载后的文件在本地磁盘中的绝对路径。数据集分训练集 iris_training.csv（120 条）与测试集 iris_test.csv（30 条）。

csv 文件内容：第 1 行是说明行（120 个样本、4 个属性、3 个类别名），其后每行为”4 个属性 + 1 个标签”；标签用数字编号：0-山鸢尾、1-变色鸢尾、2-维吉尼亚鸢尾。

split() 函数：通过指定的分隔符对字符串切片并返回列表；用它自动获取文件名，下载其他数据集时只要改变 URL 地址即可。

6.5 易错点

  • get_file() 返回本地绝对路径而非文件内容；课件第 11 页把 split 误写成 spit（原文如此），实际必须写 split('/')。
  • header 取值是行号且从 0 开始；names 会覆盖 header 指定的列标题。
  • as_matrix() 已移除，新代码用 DataFrame.values 或 np.array(df)。
  • 4×4 矩阵子图序号不能写 i*4+j（第 1 个会变 0），应为 4*i+(j+1)；对角线应用 text() 而非 scatter()。

附录：matplotlib.tight_layout() 参数补充说明

参考：https://matplotlib.org/stable/api/tight_layout_api.html

画布中有多个子图时，tight_layout() 会自动调整子图参数使之填充整个图像区域；但默认参数并不一定达到想要的效果，此时需设置其参数。默认值形如：

  • rect：指定子图区域（[left, bottom, right, top]，0~1）；设置后所有子图都调整到该矩形区域中（见 6.1 小节）。
  • pad：设置画布与子图之间的间距，默认为 1.08。
  • h_pad、w_pad：设置相邻子图之间的间距。
