3.1 初识 Python

3.1.1 版本与语言定位

  • Python 由 Guido van Rossum 于 1989 年开始设计，1991 年发布 V0.9.0。
  • 主要版本脉络：1994 年 V1.0（新增函数式工具）→ 2000—2002 年 V2.0（内存回收机制、列表推导式）→ 2008 年 V3.0（不向下兼容，官方提供 2to3 转换工具）。
  • 课件给的是 解释型语言 的定位：
类型 工作机制 典型语言
编译型语言 执行前由编译器把整个源程序翻译成机器语言，运行时直接跑可执行程序 C、C++
解释型语言 运行时由解释器对源程序逐条翻译、逐条执行 Python、JavaScript
折中（虚拟机） 先编译成字节码，再由虚拟机把字节码翻译为机器语言 Java
  • Python 的具体执行流程：首次执行时解释器把源文件 .py 编译成字节码文件 .pyc；再次执行时直接加载 .pyc 并逐行解释；解释器会自动检查时间戳，源程序改动后自动重新生成 .pyc——这样既跨平台又加快了运行效率。
  • 课件特别强调：Python 中并没有独立的编译系统，所以仍属于解释型语言。

3.1.2 自由软件与开源软件

  • 自由软件（free software）：Richard M. Stallman 的经典表述是——“free” 指的是 liberty（自由），而非 price（价格）；用户有运行、拷贝、分发、学习、修改和改进软件的自由。
  • GNU（GNU’s Not Unix!）：反对使用专利软件，主张程序必须附带源代码。
  • copyleft：对源代码的任何改进和修改，改动后的源代码必须公开，从而保证自由软件传播的延续性。
  • GPL（GNU 通用公共许可协议）：允许自由运行、拷贝、修改、再发行 GPL 授权的软件，但不允许把修改后或衍生的代码作为私有商业软件发布和销售。
  • 开源软件（open source）：允许软件授权收费；软件本身可开源免费提供，但服务与维护可以收费；开源社区可以接受商业公司资金支持。
  • 免费软件（freeware）：免费提供给用户使用，通常有限制；源码不一定公开，用户也没有复制、研究、修改和再散布的权利。

一句话区分：自由软件强调”自由”，开源软件强调”开放”，免费软件只强调”不要钱”。

3.1.3 Python 的特性（课件结论）

  • 语法简洁、结构清晰、简单易学；
  • 功能强大、资源丰富：丰富的标准库（网络、文件、GUI、数据库、文本、加密、爬虫、机器学习等），庞大的第三方库（>12 万），如 NumPy、SciPy、Matplotlib、Pandas、wordcloud；
  • 开源、开放体系：世界上最大的、针对单一编程语言的计算生态；
  • 高可扩展性：被称作”胶水语言”；
  • 高可移植性：对底层操作系统有良好的兼容性。

课件还引用了 IEEE 2018/2017 顶级编程语言排行榜与 TIOBE 排行榜，说明 Python 是”年度发展最快””开源项目钟爱”的语言；最后用一句话收尾：Life is short, you need Python.

3.2 第一个 Python 程序

课件用一个完整的例子引入：判断变量 num 是否是正数。

3.2.1 注释语句

  • 注释是对程序进行说明的语句，在程序运行过程中不被执行。
  • 单行注释以 # 开头；多行注释可以直接使用多行字符串（三重引号）充当（详见 3.4.1）。

3.2.2 赋值语句与动态类型

  • 动态类型语言：不需要声明变量，变量在使用前必须赋值，类型检查在运行阶段完成（Python、JavaScript、Ruby…）。
  • 静态类型语言：必须声明变量，类型检查在编译阶段完成（C、C++、Java…）。

3.2.3 条件语句与语句块：靠缩进

Python 的语句块直接通过代码的缩进来表示，而不是靠花括号。课件用同一段代码演示：改变语句缩进，程序逻辑就会发生变化。

对照 C 语言：C 编译器忽略缩进，else 按”就近原则”配对，容易产生悬挂 else（dangling else）问题；Python 按缩进识别语句块，可以有效避免错误配对。

PEP8 规范：语句块的缩进为 4 个空格。
常见错误：混用键盘上的 Tab 键和空格键，造成缩进不一致。

3.4 常量、变量和表达式

3.4.1 数据类型、常量和变量

（1）6 种标准数据类型

数字、字符串、列表、元组、字典、集合。本小节只展开”数字”和”字符串”。

数字（Numbers）

  • 整型（Integer）：正整数、负整数、零。Python3 中的整数可以任意大，不用担心位数不够导致溢出：

  • 浮点数（Float）：即小数，如 3.14、-0.28；也支持科学计数法，例如太阳直径 1392000 千米 = 1.392×10⁹ 米 → 1.392E9。
  • 布尔值（Boolean）：True（真）—— 1，False（假）—— 0；注意是 True/False，不是 true/TRUE/false/FALSE。
  • 复数（Complex）：形如 a+bi，例如 1+2i，有实部和虚部。

字符串（String）

  • 使用成对的单引号或双引号括起来，如 "Python"、'666'、'3.5'；
  • 使用三重引号指定一个多行字符串；
  • 多行注释：可以直接使用多行字符串作为程序的注释。

（2）标识符（Identifier）

标识符是变量、函数、数组、文件、对象等的名字：

  • 第 1 个字符必须是字母或下划线；
  • 其他字符可以由字母、下划线或数字组成；
  • 长度任意；
  • 大小写敏感（score 与 Score 不同）；
  • 不能与 Python 关键字重名；
  • Python3 中标识符支持非英语字符（Unicode 字符集支持的字符都可以），但建议尽量使用英文；
  • 命名应尽量有意义。

合法/非法示例（课件给出）：test_data、test_data_1、_y、_ 合法；1test、1_test 非法。

（3）常量（constant）

  • 常量指数、字符串、布尔值、空值等，如 -10086、3.5、"Python"、True、False、None；
  • Python 中没有命名常量——不能给常量起一个名字。

（4）变量（variable）

  • Python 的变量不需要声明；
  • 其数据类型由所赋的值决定；

** 幂运算 2**3 → 8

  • 除法运算的结果是浮点型的精确值（即使两个整数相除）；

本讲易错点清单

  1. 缩进：语句块靠缩进表示，PEP8 规定 4 个空格；不要混用 Tab 和空格（这是课件明确点出的常见错误）。
