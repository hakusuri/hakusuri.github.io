5.1 多维数组

5.1.1 为什么需要多维数组

  • NumPy 的核心数据结构是多维数组。在机器学习中，需要把输入数据转变为多维数组的形式，才能交给算法处理。
  • 现实中的数据天然是多维的。例如学生成绩表：30 行 × 5 列，行表示学生，列表示课程（语文、英语、历史、地理等）。

5.1.2 数组的下标表示

用 score[i, j] 表示二维数组中第 i 行、第 j 列的元素：

  • 二维：score[0, 0] = 85、score[0, 1] = 72 …… score[20, 4] = 78
  • 一维：score[i]，如 score[0] = 85、score[1] = 72、score[4] = 80

因此 score[i] 取出的是第 i 行这一整行（一个一维数组），score[i, j] 取出的才是某个具体元素。

5.1.3 数组的形状（Shape）与长度（Length）

  • 形状（Shape）：是一个元组，描述数组的维度，以及各个维度的长度。
  • 长度（Length）：某个维度中的元素个数。
  • 形状记为 (n0, n1, ..., ni, ...)，第 i 个分量就是第 i 个维度的长度。
数组 内容 shape

二维数组 3 行 4 列，元素 0~11 (3, 4)

5.2 创建 NumPy 数组

5.2.1 NumPy 是什么

NumPy 是 Python 科学计算的基础库，课件总结其特点如下：

  1. 提供了多维数组、矩阵的常用操作和一些高效的科学计算函数；
  2. 底层运算通过 C 语言实现，处理速度快、效率高，适用于大规模多维数组；
  3. 可以直接完成数组和矩阵运算，无需循环。

5.2.4 数组的属性

属性 描述
ndim 数组的维数
shape 数组的形状
size 数组元素的总个数
dtype 数组中元素的数据类型
itemsize 数组中每个元素的字节数

5.2.5 数组元素的数据类型

  • NumPy 要求数组中所有元素的数据类型必须是一致的（这一点与 Python 列表不同）。
  • 常用数据类型：
    • 整型：int8、uint8、int16、uint16、int32、uint32、int64、uint64
    • 浮点型：float16、float32、float64、float128
    • 复数型：complex64、complex128、complex256
    • 其他：bool、object、string_、unicode_
  • 在使用 Python 列表或元组创建 NumPy 数组时，所创建的数组类型由原来的元素类型推导而来；也可以在创建时用 dtype 参数显式指定。

5.2.6 创建特殊数组的函数

函数 功能描述
np.arange() 创建数字序列数组
np.ones() 创建全 1 数组
np.zeros() 创建全 0 数组
np.eye() 创建单位矩阵
np.linspace() 创建等差数列
np.logspace() 创建等比数列

(1) np.arange(起始数字, 结束数字, 步长)：创建一个由数字序列构成的数组。它是前闭后开的，数字序列中不包括结束数字；起始数字省略时默认从 0 开始，步长省略时默认为 1。

(2) np.ones(形状, dtype=...)：创建一个元素全部为 1 的数组。形状要写成元组，所以即使是 3×2 的二维数组，这里仍然要有两层括号。

(3) np.zeros(形状)：创建一个元素全部为 0 的数组。

(4) np.eye(N) / np.eye(N, M)：创建一个单位矩阵（主对角线为 1，其余为 0）；行列数不等时得到的是按行数截取的“单位阵”。

(5) np.linspace(起始数, 结束数, 元素个数, dtype=...)：创建等差数列；(6) np.logspace(起始指数, 结束指数, 元素个数, base=..., dtype=...)：创建等比数列。

易错点：arange 用步长控制结果，linspace / logspace 用元素个数控制结果，第三个参数的含义完全不同，不要混用。

5.2.7 array() 与 asarray() 的区别

5.3 数组运算

5.3.1 数组元素的切片

  • 一维数组：可以使用切片来访问 NumPy 数组中的一部分，切片方法和 Python 序列数据结构的切片一样。
  • 二维数组：b[行切片, 列切片]，逗号分隔不同维度。

  • 三维数组：t[:, :, 0] 表示取第 0 层上所有行、所有列的数据，结果是一个二维数组。

易错点：切片是“前闭后开”的，b[0:2] 只取下标 0、1 两行；用逗号分隔维度时，单独的 : 表示该维度全部取。

5.3.2 改变数组的形状

函数 功能描述
np.reshape(shape) 不改变当前数组，按照 shape 创建新的数组
np.resize(shape) 改变当前数组，按照 shape 创建数组

也可以在创建数组的同时改变形状：

  • 参数 -1：根据数组中元素总个数、以及其他维度的取值，来自动计算出这个维度的取值。

易错点：当改变形状时，应该考虑到数组中元素的个数，确保改变前后元素总个数相等，否则会出现错误（例如 12 个元素无法 reshape 成 5×3）。用 -1 让 NumPy 自动推算某一维，可以免去手算。

5.3.3 数组间的运算

  • 相加的两个数组的形状和长度应该一致，否则就会出现错误。
  • 一维数组可以和多维数组相加，相加时会将一维数组扩展至多维（广播）。
  • 数组之间的减法、乘法、除法运算，和加法运算规则相同。
  • 当两个数组中元素的数据类型不同时，精度低的数据类型会自动转换为精度更高的数据类型，然后再进行运算。

5.3.4 矩阵运算

  • 矩阵乘法
    • 乘号运算符 *：矩阵中对应的元素分别相乘（逐元素相乘）；
    • np.matmul() / @ 运算符：按照矩阵相乘的规则运算，@ 运算符可以连续进行矩阵乘法。

  • 转置和求逆
    • 矩阵转置：np.transpose()
    • 矩阵求逆：np.linalg.inv()

易错点：* 与 @ / matmul() 的语义完全不同 —— 前者是逐元素相乘，后者才是线性代数意义的矩阵乘法。把 A * B 误当成矩阵乘法是常见错误。

5.3.5 数组元素间的运算与 axis

函数 功能描述
numpy.sum() 计算所有元素的和
numpy.prod() 计算所有元素的乘积
numpy.diff() 计算数组的相邻元素之间的差
np.sqrt() 计算各元素的平方根
np.exp() 计算各元素的指数值
np.abs() 取各元素的绝对值
  • 轴（axes）：数组中的每一个维度被称为一个轴。
  • 秩（rank）：轴的个数。一维数组 rank=1，二维数组 rank=2，三维数组 rank=3，四维数组 rank=4。
  • 二维数组中：axis=0 表示沿第 0 个维度（行方向）运算，即按列求和；axis=1 表示沿第 1 个维度（列方向）运算，即按行求和。

5.4.1 创建矩阵

numpy.matrix 可以从字符串 / 列表 / 元组 / 数组创建矩阵。参数为字符串时，同一行的元素用空格分隔，行与行之间用分号 ; 分隔。

5.4.2 矩阵运算

矩阵相乘：矩阵对象的 * 就是矩阵乘法（与 ndarray 的逐元素 * 不同）。

对应的算式：

转置、求逆：矩阵转置用 .T，矩阵求逆用 .I；一个矩阵乘以它的逆等于单位阵。

非方阵的转置、求逆运算：非方阵照样可以转置；.I 求出的是伪逆，其形状与转置后的形状一致。

5.4.3 矩阵 VS 二维数组

比较项 矩阵 matrix 二维数组 ndarray
运算符号 简单（* 即矩阵乘法） 需要用 @ / matmul()
维度能力 只能表示二维 能够表示高维数组
灵活性 — 数组更加灵活，速度更快

建议：日常计算优先使用 ndarray（如 A @ B）；matrix 主要出于历史原因保留，适合作为理解矩阵运算的入门工具。

5.4.5 伪随机数与随机种子

  • 伪随机数：由随机种子，根据一定的算法生成的。
  • 随机种子：指定随机数生成时所用算法开始的整数值。
  • 规则：
    • 如果使用相同的 seed() 值，则每次生成的随机数都相同；
    • 如果不设置这个值，则系统根据时间来自己选择这个值，此时每次生成的随机数因时间差异而不同；
    • 设置的 seed() 值仅一次有效；
    • 随机数产生的算法，和系统有关。

易错点：seed() 仅一次有效 —— 设置一次种子后，再调用随机函数又会得到不可复现的新序列；想复现结果必须每次调用前都重新设置。

5.4.6 shuffle() 打乱顺序

  • np.random.shuffle() 用于打乱顺序，作用对象是序列（Python 列表、NumPy 数组等），并且是原地打乱。
  • 对于多维数组，使用 shuffle() 函数只打乱第一维元素。
