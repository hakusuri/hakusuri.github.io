7.1 数字图像基本概念

7.1.1 图像的离散化

  • 连续图像：人眼直接感受到的图像。
  • 数字图像：把连续图像数字化、离散化之后得到的图像，它是对连续图像的一种近似。

一句话理解：计算机存不下”连续”的光，只能把它按网格切成一个个点、再把每个点的亮度/颜色量化成有限的整数——这就是数字图像。

7.1.2 像素、位图与位深度

术语 含义
像素（Pixel） 图像中的一个最小单位
位图（bitmap） 通过记录每一个像素值来存储和表达的图像
色彩深度 / 位深度 位图中每个像素点用多少个二进制位来表示
  • BMP：Windows 系统的标准位图格式。

课件给出的存储量计算示例（务必掌握这个换算）：

图像类型 位深度 512×512 图像的存储量
二进制（二值） 1 位/像素 512×512 bit = 256 Kb = 32 KB
灰度图像 8 位/像素（1 字节） 512×512×8 bit = 256 KB
24 位彩色 RGB 24 位/像素（3 字节） 512×512×24 bit = 768 KB

记忆要点：1 字节 = 8 位；二进制只有 1 位，所以二值图像最省空间。

7.1.3 五类常见图像

（1）二值图像（Binary Image）

  • 每个像素只有 2 种可能取值，用 1 位二进制表示，位深度为 1。
  • 黑白图像：只有黑色和白色两种颜色。在图像处理和分析时，常常首先对图像进行二值化处理。
  • 只要是仅有两种颜色的图像，都可以被称为二值图像（不一定是黑白色）。

（2）灰度图像（Gray Image）

  • 每个像素使用 1 个字节表示，位深度为 8，可以表示 256 种级别的灰度。
  • 0 表示黑色，255 表示白色；数值表示光学强度，255 是光学强度最大的状态，0 是黑色。

（3）彩色图像（RGB）

  • 每个像素都有红（R）、绿（G）、蓝（B）三个分量。
  • 1 个像素点使用 3 个字节，位深度为 24 位。
  • 24 位可以表示 256×256×256 = 16 777 216 种颜色（约 1677 万色）。
  • 典型取值：(0,0,0) 黑色、(255,255,255) 白色、(255,0,0) 红色。

（4）RGBA 图像

  • 32 位彩色：RGB 图像 + 8 位透明度信息 Alpha。
  • 1 个像素点使用 4 个字节，位深度为 32 位。
  • 例：Alpha = 255 / 180 / 128 / 0（0 表示全透明）。

（5）256 色彩色图像（调色板图像）

  • 每个像素用 8 位二进制表示，取值是调色板中的索引值。
  • 对于不同的图像，所对应的这 256 种颜色的集合是不一样的。
  • 在保存和加载这种类型的位图时，需要将调色板和图像一同保存和加载。

7.1.4 图像格式与图像压缩

图像压缩：适当降低图像质量来减小它所占用的空间；不同的图像压缩算法对应不同的图像格式。

格式 压缩方式 特点与适用场景
BMP 不压缩 占用存储空间大，不支持文件压缩，不适用于网页
JPEG 有损压缩 压缩率高、所占空间小；适合色彩丰富、细节清晰细腻的大图像；不适合颜色较少、有大块相近颜色区域、或亮度差异明显的简单图片；每次编辑都会降低质量，不适合多次编辑
PNG 无损压缩 Portable Network Graphics；适合有规律渐变色彩的图像
GIF — Graphics Interchange Format；支持静态和动态格式，动态图由多幅图片组成、循环显示形成动画；只支持 256 色，适合色彩简单、颜色较少的小图像
TIFF 支持多种编码 Tag Image File Format；定义了 4 类格式：二值（TIFF-B）、黑白灰度（TIFF-G）、带调色板彩色（TIFF-P）、RGB 彩色（TIFF-R）；支持 RGB、JPEG 等多种编码；印刷行业最常用；Web 浏览器不支持

7.1.5 色彩模式

  • 二值图像、灰度图像、RGB 图像、RGBA 图像（前面已介绍）。
  • CMYK（印刷四分色）：
    • C：Cyan = 青色
    • M：Magenta = 洋红色
    • Y：Yellow = 黄色
    • K：blacK = 黑色
  • YCbCr：
    • Y：亮度
    • Cb：蓝色色度
    • Cr：红色色度
  • HSI：
    • H：色调
    • S：饱和度
    • I：亮度

7.1.6 图像类型

  • 序列图像：时间上有一定顺序和间隔、内容上相关的一组图像；其中每幅图像称为帧图像，帧图像之间的时间间隔是固定的（本质就是视频）。
  • 深度图像（Depth Map）：一种三维场景信息的表达方式，每个像素点的取值代表这个点离摄像机的距离；采用灰度图表示，每个像素点由一个字节表示；注意像素取值并不代表实际距离，颜色的深浅只代表相对距离的远近。

7.2 Pillow 图像处理库

7.2.1 为什么用 Pillow

库 说明
matplotlib.image 仅支持导入 PNG 格式的图像，且功能有限
PIL（Python Imaging Library） 功能丰富、简单易用，但仅支持 Python 2.x，且已经停止更新
Pillow 在 PIL 的基础上发展而成，支持 Python 3

  • 安装：

本讲易错点清单

  1. 位深度与字节换算：二值 1 位/像素、灰度 8 位、RGB 24 位、RGBA 32 位；1 字节 = 8 位。512×512 灰度图 = 256 KB，RGB 则为 768 KB。
  2. 灰度约定：0 是黑、255 是白；做颜色反向就是 255 - 像素值。
  3. 数组维度：灰度图 → 二维数组；彩色 RGB 图 → 三维数组（第三维是 3 个通道）。
  4. resize() vs thumbnail()：前者返回新对象、不改原图；后者原地修改且返回 None，不能写成 img = img.thumbnail(...)。
  5. crop() 参数顺序是 (左, 上, 右, 下)（左上角、右下角），别和 (x, y, w, h) 混淆。
  6. matplotlib.image 只支持 PNG；要处理 JPEG/BMP/GIF/TIFF 等格式请用 Pillow。
  7. PIL 已停止更新且只支持 Python 2，新代码请统一用 Pillow。
  8. MNIST 形状：train_x 是 (60000, 28, 28)，train_y 是 (60000,)，dtype=uint8（取值 0~255）。
  9. 显示灰度图要加 cmap="gray"，否则 matplotlib 会用默认伪彩色映射，看起来颜色很怪。
  10. JPEG 是有损压缩，反复编辑保存会持续掉画质；需要多次编辑的素材请用 PNG/TIFF。

与后续深度学习内容的衔接

  • 图像在计算机里的本质是数组：这个认知是后面所有卷积神经网络（CNN）处理图像的基础——CNN 的输入就是一个形状为 (样本数, 高, 宽, 通道数) 的四维张量。
  • 本次学的 np.array(image) 正是把图像”喂”给神经网络的必经一步；MNIST 则是后面手写数字识别的标准练手数据集。
