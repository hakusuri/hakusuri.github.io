4.1 内置数据结构

4.1.1 序列数据结构

核心概念要点

  • 序列（sequence）：成员是有序排列的；每个元素的位置称为下标或索引；通过索引访问序列中的成员（例如 “abc” ≠ “bca”）。
  • Python 中的序列数据类型有：字符串、列表、元组。
  • 列表和元组都可以存放不同类型的数据（混合类型）。
  • 表示方法：列表用方括号 [ ]，元组用小括号 ( )。列表：[1,2,3]；元组：(1,2,3)。
  • 列表（list）：可变，可以添加、修改、删除元素。
  • 元组（tuple）：一经定义，元组的内容不能改变，因此元组不支持更新操作。
  • 索引（下标）：分正向索引（从 0 开始）和逆向索引（从 -1 开始）。对 [1,2,3]：正向 0 1 2，逆向 -3 -2 -1；对 6 个元素的序列，正向 05，逆向 -6-1。
  • 切片：一次性从序列中获取多个元素，写法为 [开始位置:结束位置]，是前闭后开的（切片不包括结束位置的元素）。
    • 开始位置缺省：从第一个元素开始；
    • 结束位置缺省：到最后一个元素为止；
    • 开始与结束位置都缺省：取到整个序列。
  • 打印：print()；获取序列长度：len(序列名称)。

常见错误 / 易错点

  1. 元组不可更新：元组一经定义后就不能更改，因此元组不支持更新（append/insert/del 等）操作。
  2. 切片前闭后开：list1[2:] 的结果是 [3]，切片不包括结束位置的元素。
  3. 单元素元组必须加逗号：(1) 是整数，(1,) 才是元组。
  4. 变量名要前后一致：定义与使用时变量名不同会直接报 NameError。
  5. 列表是可变的、元组是不可变的，这是两者最本质的区别。

4.1.2 字典和集合

核心概念要点

字典（Dictionary）

  • 每个字典元素都是一个键/值对（key/value）；键是”关键”，值是与关键对应的取值。
  • 字典中的元素是无序的，因此每次显示的顺序可能不同。
  • 创建：dic_score = {"语文":80, ...}；值可以是嵌套字典/列表。
  • 打印字典、访问字典中的元素：字典名[键]。
  • 判断字典中是否存在某元素：in 运算符。
  • 遍历字典：keys() 返回所有键；values() 返回所有值；items() 返回所有键值对。
  • 更新字典：添加元素、修改指定元素的取值 —— 都是通过 字典名[键] = 值 完成。
  • 合并字典：update() 将另一个字典中的元素追加到字典中。
  • 删除字典中的元素：pop(关键字) 删除指定元素；clear() 清空所有元素；此外 Python 还提供了 del 语句，可以删除字典中指定的元素，或删除字典本身。

集合（set）

  • 由一组无序排列的元素组成。
  • 可变集合（set）：创建后可以添加、修改和删除其中的元素。
  • 不可变集合（frozenset）：创建后就不能再改变了。
  • Python 会自动把集合中重复的元素清理掉（如 {1,2,3,4,5,4,5} 会变成 5 个元素）。
  • 集合中的元素是无序的，因此不能通过下标来访问。
  • 打印集合、获取集合长度、遍历集合的方法，与其他内置数据类型类似。

常见错误 / 易错点

  1. 字典是无序的，每次显示的顺序可能不同，不要依赖输出顺序。
  2. 集合元素无序，不能用下标访问（set1[0] 会报 TypeError）。

4.2 函数和模块

4.2.1 函数

核心概念要点

  • 函数（function）：实现某种特定功能的代码块。使用函数可以让程序简洁、可重复调用、封装性好、便于共享。
  • 函数分为系统函数和用户自定义函数。（课件：Python 3.6.2 版本一共提供了 68 个内置函数。）
  • Python 内置函数按用途可分为：数学运算函数、输入输出函数、类型转换函数、逻辑判断函数、序列操作函数、对象操作函数。
  • 定义函数：def 函数名(参数列表): 函数体
    • 形式参数（形参）：在定义时并没有确定的值，只是用来说明函数的功能；当函数被调用时，形参才得到具体的值并参与运算，求得函数值。
    • 参数列表可以为空（函数可以没有参数）；如果有多个参数，参数之间用逗号分隔。
    • 函数体可以是一条语句，也可以是一个语句块。
  • 调用函数：函数名(参数列表)，此时传入的是实际参数（实参）。
  • 通过多元赋值语句可以同时获取多个返回值。
  • 变量作用域：
    • 局部变量（Local Variable）：在函数中定义的变量，仅在定义它的函数内部有效。
    • 全局变量（Global Variable）：在函数体之外定义的变量，在定义后的代码中都有效，包括在它之后定义的函数体内。当全局变量与函数内部定义的局部变量同名时，它在函数内部失效。
  • 参数的传递：按值传递 —— 形参和实参分别存储、相互独立；在函数内部改变形参的值时，实参的值不会随之改变。
  • 参数的默认值：def 函数名(参数1=默认值, 参数2=默认值): 函数体。当函数中有多个参数时，参数的默认值只能从最右边开始依次设置。
  • 向函数内部批量传递数据：可以使用列表、字典变量作为参数。当使用列表或字典作为函数参数时，在函数内部对列表或字典的元素所做的修改，会改变实参的值。

4.2.2 模块、包和库

核心概念要点

  • 模块（Module）：模块是一个 Python 文件（.py），拥有多个功能相近的函数或类。作用：便于代码复用、提高编程效率、提高代码的可维护性、避免函数名和变量名冲突。
  • 包（Package）：为了避免模块名冲突，Python 引入按目录来组织模块的方法。一个包对应一个文件夹，把功能相近的模块（Python 文件）放在同一个文件夹下；作为包的文件夹下有一个 __init__.py 文件。子包：子目录中也有 __init__.py 文件。
  • 库（Library）：具有相关功能的模块或包的集合。
  • 包的结构示例：package_a 文件夹下有 __init__.py、模块 module_a1.py、module_a2.py，还有子包 subpack_ab；子包中也有 __init__.py 和 2 个模块。（课件第 3 页为包结构示意图。）
  • 导入模块 / 包 / 库：
    • import 名称 as 别名（导入整个包）
    • from 模块名 import 函数名 as 函数别名（导入包中指定的模块或子包）
    • 课件提示：这种 from ... import ... 方式是 PEP8 Python 编码规范推荐的方式。
  • 导入语句的作用域：在程序顶部导入模块，作用域是全局的；在函数的内部使用导入语句，作用域就是局部的。
  • 建议的导入顺序：标准库/模块 → 第三方库/模块 → 自定义模块。
  • 使用模块/包/库中的函数和变量：模块/包/库名.函数名(参数列表)、模块/包/库名.变量名。
  • 自定义模块：将常用函数的定义放在一个 .py 文件中（如 mymodule.py）。当函数较多时，可以按照功能将它们放在不同的模块中；一个应用程序中可以定义多个模块。

4.3 Python 面向对象编程

核心概念要点

  • 面向对象的程序设计（Object-oriented programming，OOP） 与 面向过程的程序设计（Process-oriented programming，POP） 是两种编程思想；面向对象把属性和方法封装在一起（例如对象的姓名、年龄、性别是属性，说话、吃东西、打招呼是方法）。

  • 对象的属性和方法：通过”对象名.成员”访问 —— 属性用 对象名.属性名（如 zhangsan.name），方法用 对象名.方法名()（如 zhangsan.speak()）。用对象名访问成员变量和成员函数。

  • 类（class）：具有相同的属性和方法的对象集合。对象是类的实例（instance）。

  • 继承描述了类之间的层次关系：子类（派生类）继承了父类（基类）的全部属性和方法，并且也有自己特有的属性和方法。

  • 类和对象并非仅限于具体的事物，它也可以是一种抽象的概念或者规则。

  • 声明类：class 类名: 类属性=初值; 方法(参数列表)。

  • 类属性：

    • 是类中所有对象共同拥有的属性，它在内存中只存在一个副本；
    • 可以通过类名访问，也可以被类的所有对象访问；
    • 在类定义之后，可以通过类名添加类属性，新增的类属性也被类和所有对象共有；
    • 修改类属性，所有实例的值都会发生变化。

  • 类的特殊属性：

    类属性 含义
    __name__ 类的名字（字符串）
    __doc__ 类的文档字符串
    __bases__ 类的所有父类组成的元组
    __dict__ 类的属性组成的字典
    __module__ 类所属的模块
    __class__ 类对象的类型

  • 访问类属性：类名.类属性 或 对象名.类属性。

  • 创建对象：对象名 = 类名()；对象拥有类中的所有属性和方法。

  • 实例方法中必须有一个参数 self，而且它是参数列表中的第一个参数。由同一个类可以生成很多个对象，每一个对象都有一个专属的 self，代表这个对象自身。

  • 动态添加对象属性：创建对象之后可以动态添加实例属性；它是动态添加的实例属性，只属于该对象自己，重新创建的其他对象没有这个属性。

  • 删除对象：del 对象名；执行后对象就不存在了，再访问会出现错误提示。

  • 构造函数 __init__：在创建对象时，用来完成初始化操作；当创建对象时，系统会自动调用构造函数；可以把对成员变量赋初值的语句写在构造函数中，从而保证每个变量都有合适的初始值。

  • 析构函数 __del__：在清除对象时，回收和释放对象所占用的资源。在 Python 中，构造函数和析构函数也可以省略。

  • 类方法和静态方法：都可以通过类名或对象名调用；类方法不能访问实例属性，但可以访问类属性；静态方法不能访问实例属性，也不能直接访问类属性（但可以通过类名引用类属性）。

  • 公有变量和私有变量：公有变量可以在类的外部访问；保护变量只允许其本身和子类访问；私有变量不允许在类的外部访问。

    • 私有变量：__变量名；保护变量：_变量名；专有变量/方法：__变量名__。

  • 继承（inheritance）：子类能够继承父类中所有非私有的成员变量和成员函数。写法：class 子类名(父类名):。

类方法 / 静态方法（课件以文字描述）：类方法可以通过类名或对象名调用，第一个参数必须是 cls，不能访问实例属性，但可以访问类属性；静态方法通过类名或对象名调用，没有 self 或 cls 参数，不能访问实例属性，也不能直接访问类属性（可通过类名引用类属性）。

注：Python 中分别用 @classmethod（类方法）与 @staticmethod（静态方法）装饰器定义，课件原文以文字说明为主，未给出装饰器写法。

小节要点回顾

  • 类（class）：对具有相同属性和方法的一组对象的描述，它定义了所有对象所共有的属性和方法。
  • 对象（object）：是类中的一个具体的实例（instance）。
  • 属性（attribute）：是类和对象中的变量。
    • 类属性：定义在类的内部、方法的外部，是类中所有对象共同拥有的属性。
    • 实例属性：也叫成员变量，在每个对象中都有自己的副本。
  • 方法（method）：是在类中所定义的函数，它描述了对象能执行的操作。
    • 实例方法/成员函数：只能通过对象名调用，第一个参数必须是 self（构造函数和析构函数属于此类）。
    • 类方法：可以通过类名或对象名调用，第一个参数必须是 cls。
    • 静态方法：通过类名或对象名调用，没有 self 或 cls 参数。
  • 成员变量：公有变量、保护变量和私有变量。
  • 继承：是子类自动地共享父类中的属性和方法的机制。

常见错误 / 易错点

  1. self 必须是实例方法的第一个参数。
  2. 动态添加的实例属性只属于该对象，其他对象访问会报 AttributeError: 'Person' object has no attribute '...'。
  3. 类属性与实例属性的区别：Person.money = 9000 修改类属性，所有实例都变；zhangsan.money = 5000 只是给 zhangsan 新建了一个实例属性，不影响类和其它对象。
  4. 删除对象后不能再访问，否则报 NameError。
  5. 私有变量不允许在类的外部访问；保护变量只允许本身和子类访问。
  6. 构造函数与析构函数可以省略；构造函数在创建对象时由系统自动调用。

4.4 文件

核心概念要点

  • 打开文件：文件对象 = open(文件名, 访问模式)。

  • 路径：

    • 绝对路径：从盘符开始的路径，如 C:\windows\system32\cmd.exe、D:\Program Files\Anaconda3\lib\site-packages\ipykernel\__main__.py。
    • 相对路径：从**当前目录（工作目录）**的路径，如当前目录为 D:\jupyter\example 时，file.txt 指向 D:\jupyter\example\file.txt，tensorflow\file.txt 指向 D:\jupyter\example\tensorflow\file.txt。

  • 课件第 3 页给出了”获取当前路径（current working directory）“的概念。

    • 注：课件该页仅给出概念，未配示例代码。

  • 访问模式：

    访问模式 执行操作
    'r' 以只读方式打开文件
    'w' 以写入方式打开文件，会覆盖已经存在的文件
    'a' 以写入方式打开文件，在末尾追加写入
    可读写方式 以可读写的方式打开文件
    'b' 以二进制模式打开文件
    't' 以文本模式打开文件（默认）
    'rb' 二进制读模式
    'wb' 二进制写模式
    'ab' 二进制追加模式

  • 使用 open() 函数成功打开一个文件之后，它会返回一个文件对象；否则就会返回一个错误。

  • 例：在 C 盘根目录下创建文本文件 myfile.txt，然后使用 open() 函数打开它。只有文件名时，默认为当前工作目录；访问模式是 "w" 时，如果在工作目录下找不到这个文件，就会自动创建它。

  • 关闭文件：文件对象.close()。

    • Python 有垃圾回收机制，会自动关闭不再使用的文件；
    • 但在对文件进行了写入操作后，应该立刻关闭文件，以避免意外事故造成的错误。

  • 读取文件的内容：

    • read() 方法：读取整个文档；
    • readline() 方法：每次只读取文件中的一行；
    • 也可以指定字节数：read(字节数)、readline(字节数)；
    • 读取过程中涉及文件指针的移动。

  • 向文件中写入数据：文件对象.write(写入内容)。

    • 在使用 write() 函数之前，要确保 open() 函数的访问模式支持写入；
    • 写入成功之后，会返回写入的字符数（一个整数）。

4.5 异常处理

核心概念要点

  • 异常：程序运行时的错误，对应一个 Python 对象。

  • try-except 语句的执行规则：

    • 在程序运行时，解释器尝试执行 try 语句块中的所有代码；
    • 如果语句块被执行完后没有异常发生，就会忽略 except 后的代码；
    • 当某个 except 所指定的异常发生后，会忽略 try 子句中剩余的语句，直接跳转到对应异常的处理代码处执行。

  • Python 中常见的异常：

    异常 含义
    IOError 输入/输出异常（基本上是无法打开文件）
    ImportError 无法导入模块或包（基本上是路径问题或名称错误）
    IndentationError 缩进错误（代码没有正确对齐）
    NameError 没有声明、或初始化对象
    KeyError 试图访问字典里不存在的键
    AttributeError 试图访问一个对象没有的属性
    TypeError 类型不匹配
    ValueError 传入一个调用者不期望的值，即使值的类型是正确的

  • Python 异常类的继承关系：根类为 BaseException，其下依次有 SystemExit、KeyboardInterrupt、GeneratorExit、Exception；Exception 之下有 StopIteration、ArithmeticError（→ FloatingPointError、OverflowError、ZeroDivisionError）、AssertionError、AttributeError、BufferError、EOFError、ImportError、LookupError（→ IndexError、KeyError）、MemoryError、NameError、OSError、ReferenceError、RuntimeError、SyntaxError（→ IndentationError）、SystemError、TypeError、ValueError 等，另有 Warning 分支。

  • finally 子句：无论异常是否发生，都会执行。

    • 如果 try 语句块中没有出现任何运行时错误，会跳过 except 语句块，执行 finally 语句块的内容；
    • 如果出现异常，则会先执行 except 语句块的内容，再执行 finally 语句块的内容；
    • finally 语句块经常用于关闭资源等清理工作。

  • Exception：是所有非系统退出类异常类的基类；在编程时，可以通过捕获它，来避免程序遇到错误而退出。

  3. finally 子句无论异常是否发生都会执行，因此适合做”关闭资源”等清理工作。

4.6 上下文管理器

核心概念要点

  • with 语句：使用 with 语句替代 try-finally 语句，代码更加的简洁清晰。
  • 对于需要对资源进行访问的任务，无论在代码运行过程中是否发生异常，都会执行必要的清理操作、释放资源。
  • with 语句完成时会自动关闭文件；如果再次读取这个文件，就会出现文件关闭的错误提示：ValueError: I/O operation on closed file.。
  • 上下文管理器：
    • 是 Python 中的一种协议，它保证了每次代码执行的一致性；
    • 一旦进入上下文管理器，就一定会按照规定的步骤退出；
    • 如果合理设计了退出上下文管理器的步骤，就能够很好地处理异常；
    • 上下文管理器被最多用到的场景是资源清理操作；
    • 实现上下文管理器：只要在类定义时，实现 __enter__() 方法和 __exit__() 方法即可。
  • 执行顺序：
    • 在 with 语句块执行前，首先会执行 __enter__() 方法；
    • 当 with 语句块执行结束，无论是否出现异常，都会调用 __exit__() 方法；
    • 通常将清除、释放资源的操作写在 __exit__() 方法中；
    • 如果 with 语句块正常结束，那么 __exit__() 的三个参数全部是 None；如果发生异常，那么这三个参数的值分别是异常的类、实例和跟踪记录。
